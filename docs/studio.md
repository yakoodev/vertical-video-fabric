# Студия монтажа — что умеет и как этим пользоваться

Студия открывается из «Моментов» (✂ Монтаж или E на моменте). Слева — вкладки
библиотеки, по центру — превью 9:16, справа — инспектор, внизу — таймлайн.
Превью рисуется тем же движком, что и рендер: что видишь, то и получишь.

## Быстро

| Хочу | Где |
|---|---|
| Чтобы клип «ожил» за секунду, без ИИ | инспектор → «⚡ Автомонтаж» (или в «Моментах» «⚡ Автомонтаж ★» для всех избранных) |
| Вырезать паузы и «ээ/короче/типа» | инспектор → «Паузы и слова-паразиты» |
| Субтитры как у Hormozi/MrBeast | библиотека → «Текст» → стиль субтитров на весь клип |
| Покрасить слово / эмодзи над словом | выдели слой субтитров → кликни слово в инспекторе |
| Титр, плашку, график, счётчик, ТОП-3… | библиотека → «Шаблоны» (⚙ — настроить перед вставкой) |
| Эмодзи и стикеры | библиотека → «Стикеры» (поиск по-русски) |
| Звук на акцент (whoosh, boom, pop…) | библиотека → «Звуки» (▶ — послушать) |
| Шаблон мема / своя картинка | библиотека → «Мемы» |
| Нарисовать картинку ИИ / найти в интернете | библиотека → «Создать» |
| Наезд камеры на реакцию | инспектор → «Камера» (панч-ин, бум с тряской…) или «✨ Наезды по речи» |
| Вебка сверху, игра снизу | инспектор → «Раскладка (вебка)» (🎯 найдёт вебку сама) |
| Чат стрима на экране | шаблон «Чат стрима» (нужен импортированный чат Twitch) |
| ИИ-ассистент словами | библиотека → «ИИ» (нужен Gemini; без VPN — `GEMINI_PROXY_URL`) |

## Слои на кадре

* Клик по слою — выделить; тащить — двигать; уголок — масштаб; кружок сверху —
  поворот (Shift — шаг 15°). Двойной клик по тексту — править прямо на кадре.
* У свойств «Положение» есть ◆: поставил ключ — между ключами плавный переход.
  Если у свойства уже есть ключи, перетаскивание на кадре ставит ключ в текущий момент.
* Ctrl+D — копия слоя, Del — удалить, Ctrl+Z — шаг назад (любая правка клипа).

## Таймлайн

Дорожки «Графика 1…8» (выше дорожка — выше слой в кадре), «Клипы», «Субтитры»,
«Вставки», «Звуки», «Камера» (ромбы — ключи наезда), «Звук» (волна речи).
Блоки двигаются и тянутся за края, слои перетаскиваются между дорожками,
из библиотеки можно бросать прямо на дорожку. S — разрезать кусок, ←/→ — кадр,
Shift+←/→ — секунда, пробел — плей/пауза.

## Рендер

Порядок: куски (с вырезанными паузами) → раскладка, кроп, лук → камера и слои →
баннер → субтитры → вставки → звуки слоёв → громкость −14 LUFS (пик ≤ −1.5 dBFS).
