## Форматы вывода в редакторе (2026-10-24)
- Inspector footer «Формат» (9:16 / 1:1 / 4:5 / 16:9): превью клипа, холст моушн-слоёв, рамка трансформа, окно «Кадр исходника» (пропорция формата, тащится), метка на кадре, плитки холста на таймлайне и превью обложки — в пропорциях формата; 9:16 — как раньше. Клип без слоёв: смена формата сразу делает его форматом разметки
- Слои размечены в другом формате (`layers_format`): превью показывает их перекомпоновку (motion/reframe.ts — зеркало app/aspect.py), плашка под кадром «Слои размечены в X — превью показывает их перенос в Y» + «Разметить слои в этом формате» (сохраняет перенесённые слои и камеру, `layers_format` = формат; Ctrl+Z — откат). В режиме переноса слой выбирается кликом, но не тащится мышью (подсказка-тост)
- Шаблоны: карточки и диалог настройки — кадр формата разметки слоёв; вставка — слои под его опорный кадр (fitTemplate: группа одним масштабом, мем-подпись/лента/«До/После» — по долям кадра, фигуры во всю ширину/высоту тянутся)
- Инспектор слоя: предел «Ширины» — ширина опорного кадра формата разметки (1080, у 16:9 — 1920)
- Карточка клипа и диалог публикации: рамка видео по размеру готового файла (W×H)

## Инспектор редактора по вкладкам (UI-проход 2026-11, docs/redesign/audit-2026-11.md)
Все группы на месте, сменилось только «где лежит». Вкладка, свёрнутость групп и «Ещё…» запоминаются в браузере.
- Вкладки справа: **Клип · Слои · Кусок · Звук · Субтитры · Проверка** (у «Слоёв» — счётчик слоёв+вставок). Выбор на таймлайне открывает вкладку сам: слой/вставка/ключ камеры → Слои, кусок → Кусок, тишина → Звук, строка субтитров → Субтитры
- **Клип**: «Формат и концовка» (Формат 9:16/1:1/4:5/16:9, Стоп-кадр в конце — раньше в подвале), «Быстрые действия» (Автомонтаж, Найти мемы ↗, бренд + Применить бренд), Картинка (лук) (пресет, LookPicker, Зеркало), Раскладка кадра / Фон холста, Переходы, Обложка, Баннер, Паузы и слова-паразиты; **«Ещё…»** → Умный кадр (стратегия, пресет детекции, ☐ 🤖 Gemini, «Автофокус: все клипы», «Только этот план»), Границы клипов (Пересчитать), Отдать в монтажку (.otio/.edl/.xml)
- **Слои**: инспектор выбранного слоя, Слои клипа (👁/🙈), Вставки (мемы), Камера (наезды)
- **Кусок** (нет у холста): «Кусок N из M» + номера кусков (выбор без таймлайна); Скорость куска, Цвет куска, Фокус кадра (Детектор, + Точка на текущем кадре, Сохранить фокус, Очистить). Без выбранного куска — пустое состояние «Выбрать первый кусок»; открытие вкладки само выбирает первый кусок
- **Звук**: Музыка, Тишина вместо звука (Заглушить мат + стиль), Громкость исходника (+ Громче у курсора), Звуковые дорожки (у холста — только Музыка)
- **Субтитры**: «Субтитры на ролике» (☐, движок, стиль, положение) + «Строки и речь» (⛶ Править строки широко, движок, Распознать, Голоса, ✨ Ключевые, перевод/озвучка, строки)
- **Проверка**: Проверить, ☐ по рендеру, фильтры находок
- Подвал: «● настройки клипа сохранены» + Зоны; { } Файл клипа, Ко всем ★; ▶ Рендерить (1), Выбранные (N)
- Убраны дубли кнопок (функции остались): «🤖 ИИ-монтаж» из быстрых действий — есть в шапке редактора; «🎯 Автофокус» из быстрых действий — есть «Авто» под превью и «Только этот план»
- Подписи без цветных эмодзи: «Авто» (было «🎯 Авто»), «Детектор», «Автофокус: все клипы», «Заглушить мат», «+ Громче у курсора», «Сделать обложку», «Зеркало (лево↔право)», «Проверить», «Открыть редактор» (Моменты). ✨/🤖 остаются меткой ИИ
- Телефон: меню — горизонтальная лента сверху (все пункты, включая Горячие клавиши/Помощь/Настройки/Выйти)

## UI-проход 2 (2026-11-02, docs/redesign/audit-2026-11.md «Проход 2»)
Новые экраны после первого прохода — все контролы на месте, проверка `tools/ui_reach.py` (экраны explainer*, aivideo3*, editor-audio2).
- Серия: вкладка и подвкладка ИИ-видео в адресе (`/series/:id?tab=expl`, `?tab=aiv&sub=board`) — перезагрузка и ссылка открывают то же место. На телефоне вкладки серии и ИИ-видео — одна прокручиваемая лента
- **Объяснялки** (`?tab=expl`, только у проекта «ИИ-видео», модуль explainer): плашка сухого прогона; карточки владельцу (Разрешить · N ₽ / Отказать); переключатель маскотов (если их несколько)
  - «Новый ролик»: тема, длина 30–60 с, тон, ☐ сразу рендер и обложка, ✨ Сделать ролик (нужен лист маскота)
  - «Ролики»: статус, название, длина · тон, ≈ ₽; Открыть клип #N, ↻ Продолжить (ошибка/отмена), Пересобрать (готов), Отменить (идёт) / Удалить; ошибка — «что случилось» + приглушённая подсказка агенту; «▸ Сценарий и биты» — оценка (позы из библиотеки/новые/озвучка), текст, биты с позами, заметки
  - «Маскот «…»» (Сохранить в шапке): лист (⬆ Загрузить лист, Нарисовать лист / ↻ Перерисовать), имя, карта личности, характер, стиль, цвета фон/акцент/чипы, музыка под голосом, голос (TtsVoicePicker: провайдер, голос, «как говорить», ▶ Проба)

- Плеер (встраиваемый `MontagePlayer`): плей/пауза, время, прокрутка по таймлайну с кусками, звук и громкость, «Круг», на весь экран, закрыть. Пробел — плей, ←/→ — кадр, Shift+←/→ — секунда, Home/End, M — звук, F — экран, Esc — закрыть; подпись «чем отличается от рендера»; метка «монтаж обновлён» при правке агента.
- Чем играет: прокси 480p, запись или холст (метка под плеером, ход сборки прокси). Записи и прокси нет — готовый рендер и честная подпись; нет и рендера — только подпись.
- Запись удалена, а прокси есть: редактор работает (кадры, волна, превью), рендер выключен с подсказкой.
- Телефон редактора теперь играет и музыку клипа; правки агента (MCP, другая вкладка) появляются сами.

## Отдать в монтажку (2026-11)
- Группа «Отдать в монтажку»: «⬇ Пакет для монтажки (.zip)» — FCP7 .xml, .otio, .srt, файлы мемов и звуков, README; переключатель «с кусками видео» (куски 720p в архиве). Рядом остались ⬇ .otio, ⬇ .edl, ⬇ .xml.
