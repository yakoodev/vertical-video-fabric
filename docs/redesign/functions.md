## Инспектор редактора по вкладкам (UI-проход 2026-11, docs/redesign/audit-2026-11.md)
Все группы на месте, сменилось только «где лежит». Вкладка, свёрнутость групп и «Ещё…» запоминаются в браузере.
- Вкладки справа: **Клип · Слои · Кусок · Звук · Субтитры · Проверка** (у «Слоёв» — счётчик слоёв+вставок). Выбор на таймлайне открывает вкладку сам: слой/вставка/ключ камеры → Слои, кусок → Кусок, тишина → Звук, строка субтитров → Субтитры
- **Клип**: «Формат и концовка» (Формат 9:16/1:1/4:5/16:9, Стоп-кадр в конце — раньше в подвале), «Быстрые действия» (Автомонтаж, Найти мемы ↗, бренд + Применить бренд), Картинка (лук) (пресет, LookPicker, Зеркало), Раскладка кадра / Фон холста, Переходы, Обложка, Баннер, Паузы и слова-паразиты; **«Ещё…»** → Умный кадр (стратегия, пресет детекции, ☐ 🤖 Gemini, «Автофокус: все клипы», «Только этот план»), Границы клипов (Пересчитать), Отдать в монтажку (.otio/.edl/.xml)
- **Слои**: инспектор выбранного слоя, Слои клипа (👁/🙈), Вставки (мемы), Камера (наезды)
- **Кусок** (нет у холста): «Кусок N из M» + номера кусков (выбор без таймлайна); Скорость куска, Цвет куска, Фокус кадра (Детектор, + Точка на текущем кадре, Сохранить фокус, Очистить). Без выбранного куска — пустое состояние «Выбрать первый кусок»; открытие вкладки само выбирает первый кусок
- **Звук**: Музыка, Тишина вместо звука (Заглушить мат + стиль), Громкость исходника (+ Громче у курсора), Звуковые дорожки (у холста — только Музыка)

- **Проверка**: Проверить, ☐ по рендеру, фильтры находок
- Подвал: «● настройки клипа сохранены» + Зоны; { } Файл клипа, Ко всем ★; ▶ Рендерить (1), Выбранные (N)
- Убраны дубли кнопок (функции остались): «🤖 ИИ-монтаж» из быстрых действий — есть в шапке редактора; «🎯 Автофокус» из быстрых действий — есть «Авто» под превью и «Только этот план»
- Подписи без цветных эмодзи: «Авто» (было «🎯 Авто»), «Детектор», «Автофокус: все клипы», «Заглушить мат», «+ Громче у курсора», «Сделать обложку», «Зеркало (лево↔право)», «Проверить», «Открыть редактор» (Моменты). ✨/🤖 остаются меткой ИИ

## Навигация Проект → Видео → Клип (часть 1, 2026-11-05, docs/redesign/concept-2026-11.md)
Каркас заменён, функции на месте. Где что было в старом меню, теперь: Клипы → проект «Клипы» и «Публикации и аккаунты → Готовые ролики»; Файлы для монтажа → «Общие файлы» и проект «Файлы»; Одобрение и Очередь → «Входящие»; Авто → Ctrl K и ссылка на вкладке «Автопилот» проекта; Чат → проект «Чат», верхняя панель «Общий чат», /chat.
- Боковая панель: «Проекты» (ссылка на все проекты и видео, /projects), проекты списком со счётчиком видео, «+ Новый проект» (название и вид, диалог), Входящие с бейджем (карточки, вопросы, мемы), Публикации и аккаунты, Общие файлы; внизу Настройки, Помощь, маленькие Клавиши и Выйти. Счётчики — один лёгкий запрос `GET /api/nav` раз в 30 с. Узкое окно: только значки; телефон: лента сверху, текущий пункт виден
- Лестница сверху: три ступени (Проект, Видео, Клип; вне проектов — Проект, Раздел, Вкладка), текущая подсвечена, «Выберите: N» у следующей. Нажатие на другую ступень ведёт на её экран, на текущую и на шеврон — открывает список соседей. Длинный список с поиском (стрелки, Enter, Esc); у Видео первым пунктом «+ Новое видео», у Клипа последним «Все клипы этого видео». Список видео грузится только при открытии (`GET /api/nav/videos`)
- Верхняя панель: «Поиск Ctrl K», «Общий чат» (панель справа поверх любого экрана: общие переписки, «+ Новый», «Все переписки»), индикатор «нет задач / N активн.» — он же центр активности (прогресс, отменить, открыть, скрыть, Очистить, «Все задачи» → Входящие)
- Адреса: `/p/:id` проект, `/v/:id/*` видео (вкладки те же), клип пока на экране монтажа `/v/:id/candidates?clip=N`, `/inbox`, `/pubs`, `/pubs/:id`, `/files`. Первый экран `/` — последний открытый проект. `/c/:token` занят ссылкой на обложку, будущая страница клипа — `/clips/:id`
- Старые адреса ведут на новые с параметрами и якорем: `/projects/:id/*` → `/v/:id/*`, `/series/:id?tab=` → `/p/:id?tab=`, `/clips` → `/pubs?tab=ready`, `/tasks` → `/inbox?tab=tasks`, `/approvals?id=` → `/inbox?tab=approve&id=`, `/accounts` → `/pubs?tab=accounts`, `/publications/:id`, `/jobs/:id` → `/pubs/:id`, `/assets` → `/files`, `/assets?tab=project&project=N` → `/p/N?tab=files`. Работают как есть внутри каркаса: `/projects` (все видео, перенос между проектами, в том числе видео вне проектов), `/automation`, `/chat`, `/settings/*`, `/help`
- Страница проекта: заголовок (видео, готовые файлы, описание), «Новое видео» (тот же диалог создания, видео ложится в проект; файл, ссылка, «Серия и озвучка», холст), вкладки Видео · Клипы · Вопросы (счётчик) · Файлы · Чат · Лор и правила (Резюме и лор, Правила, Гипотезы) · Статистика · Автопилот; у проектов ИИ-видео ещё ИИ-видео · Канал · Объяснялки · Истории. Прежние `?tab=brief|rules|hyp|stats|autopilot|chat|aiv|channel|expl|story` и `?sub=` работают
- Проект → Видео: строки (кадр, просмотр при наведении, длительность, название и ✎, вид и дата, клипы по форматам и «без рендера», чат Twitch, «запись удалена», 🗑), W×H в подсказке строки; фильтр по статусу и поиск, когда видео больше 8; сгенерированное (ИИ-видео, истории, объяснялки, холсты проекта) строками со ссылкой на его вкладку или монтаж; порции «Показать ещё»
- Проект → Клипы: те же карточки клипов только этого проекта (`GET /api/projects/:id/clips`), фильтры Все, Вертикальные, Горизонтальные, Готово, Опубликованные, Ошибка. Те же форматы в «Готовых роликах»
- Название видео: человеческое (`display_name`): имя от владельца, название VOD, общее имя кусков («Мура Minecraft 1/4» → «Мура Minecraft»), тег файла, «Сезон 9, серия 1», «Запись 22.05.2026, 20:49», единственный клип, иначе «Стрим 31.10». Файл остаётся в подсказке и в поиске
- Входящие: вкладки Одобрение (строка «Ждут решения…», фильтры, проект; ждущие карточки целиком, решённые строкой таблицы, по нажатию — вся карточка), Вопросы (всех проектов: фильтр по проекту, «Только без ответа», те же карточки вопросов и мемов, откуда вопрос — ссылка на видео; ответ сразу уменьшает счётчик), Очередь задач (те же фильтры и строки). Компоненты те же, что у страниц видео и бывших страниц
- Проект → Файлы: те же карточки и загрузка, переключатель «Файлы проекта / Общие» (`?sub=shared`); «Общие файлы» сохраняют вкладки Общие, Проект, Все
- Клавиши: N новое видео (в проекте — сразу в него), Ctrl K, ?, цифры: вкладки проекта 1–8, вкладки видео 1–5, Входящих и Публикаций 1–3
- Ctrl K новыми словами: Новое видео, Новый проект, Общий чат, Очередь задач, Входящие, Одобрение, Вопросы всех проектов, Готовые ролики, Общие файлы, Все проекты и видео, Авто; вкладки этого проекта или видео; проекты, видео по названию и имени файла («твич», «ютуб»), клипы — сразу в монтаж
