# UI-аудит, ноябрь 2026

Вопрос владельца: «стал ли интерфейс плохим и сложным?» — после двух дней, когда агенты
независимо добавляли панели (обложки, проверка качества, скорость/цвет куска, акценты слов,
J/L-склейки, перевод/озвучка, 3D-слои, моушн-блюр, глитч-шаблоны, модули, ИИ-видео, чат,
автопилот, серии, наблюдатель VOD).

Короткий ответ: **да, в редакторе — сильно; в остальных экранах — местами**. Главная боль —
правая панель редактора. Правило прохода: ни одна функция не пропадает
(`docs/redesign/functions.md`), меняется только раскладка.

Кадры «до» и «после»: `D:\vvf-offload\tmp\uipass\before\`, `…\after\`, сравнение — `…\compare.jpg`
(демо-база, локальная копия на :8197, Vite :5297; съёмка — `tools/ui_shots.py`,
проверка достижимости — `tools/ui_reach.py`).

## Редактор клипа — правая панель (было хуже всего)

- **22 группы одной лентой**: слои, паузы, проверка, тишина, громкость, дорожки, раскладка,
  камера, *быстрые ИИ-действия посередине*, лук, субтитры, вставки, скорость, цвет, фокус,
  переходы, обложка, баннер, музыка, умный кадр, границы, экспорт. Порядок — по времени
  появления фич, не по смыслу: звук разбросан по трём местам, всё «про кусок» — по двум.
- **Видимая область ~370 px из 900**: подвал занимал ~200 px (сохранено/зоны, файл клипа/ко
  всем ★, формат, стоп-кадр, рендер). Формат и стоп-кадр — нестилизованные белые `<select>`.
- **Дубли**: «🤖 ИИ-монтаж» в шапке и в быстрых действиях; автофокус клипа — «🎯 Авто» под
  превью, «🎯 Автофокус» в быстрых действиях, «Только этот план» в «Умном кадре».
- **Три пустые группы «сегмент?»** (скорость, цвет, фокус), пока кусок не выбран.
- **Иконки вперемешку**: цветные эмодзи (🎯 ⚡ 🔎 🤬 🔊 🖼 🪞) рядом с монохромными глифами
  (▶ ⏹ ↩ ⏱ ⬇) и кнопками без иконок; «🔎 Проверка» — эмодзи в заголовке группы.
- **Свёрнутость не запоминалась**; свёрнутая группа «Субтитры» размонтировала редактор строк —
  дорожка субтитров на таймлайне пустела.
- Строка инструментов субтитров: список «как в стиле» обрезан по высоте, «✨ Ключевые»
  уезжает на отдельную строку.
- Кнопка «♪ К долям» над таймлайном переносится на две строки.

**Сделано**

- Шесть вкладок: **Клип · Слои · Кусок · Звук · Субтитры · Проверка** (без иконок, у «Слоёв» —
  счётчик). Выбор на таймлайне сам открывает нужную: слой/вставка/ключ камеры → «Слои»,
  кусок → «Кусок», тишина → «Звук», строка субтитров → «Субтитры».
  - *Клип*: «Формат и концовка» (формат + стоп-кадр, теперь обычные поля), «Быстрые
    действия» (Автомонтаж, Найти мемы ↗, бренд), лук, раскладка/фон холста, переходы,
    обложка, баннер, паузы и слова-паразиты; **«Ещё…»** — умный кадр, границы клипов,
    экспорт в монтажку.
  - *Слои*: инспектор выбранного слоя, список слоёв, вставки (мемы), камера.
  - *Кусок*: «Кусок N из M» + номера кусков для быстрого выбора; без выбора — пустое
    состояние с «Выбрать первый кусок» (вкладка сама берёт первый кусок).
  - *Звук*: музыка, тишина вместо звука, громкость исходника, звуковые дорожки.
  - *Субтитры*: «Субтитры на ролике» (вкл/движок/стиль/положение) + «Строки и речь»
    (редактор строк всегда смонтирован — таймлайн не теряет субтитры).
  - *Проверка*: проверка перед сдачей.
- Вкладка, свёрнутость каждой группы и «Ещё…» запоминаются (localStorage, в try/catch).
- Подвал: два тихих ряда + рендер — вдвое ниже; одна главная кнопка области — «▶ Рендерить (1)».
- Дубли убраны: ИИ-монтаж — в шапке редактора, автофокус клипа — «Авто» под превью и
  «Только этот план» в «Ещё… → Умный кадр».
- Иконки: эмодзи оставлены только как метка ИИ (✨ / 🤖 — тратит токены) и в строках
  списков; в кнопках — монохромные глифы или текст («Авто», «Детектор», «Заглушить мат»,
  «+ Громче у курсора», «Сделать обложку», «Автофокус: все клипы», «Зеркало»).
- Холст: вкладки «Кусок» нет (кусок один, без исходника), во «Звуке» — только музыка.
- Модули по-прежнему прячут свои кнопки (ИИ-монтаж, автофокус, джамп-каты, обложки, голоса,
  перевод) — проверено при включённых модулях; логика `moduleOn` не менялась.
- Горячие клавиши редактора не трогались (Ctrl+Z, ←/→, пробел, Del, S…).

## Моменты

- Справа четыре крупные кнопки четырёх разных цветов (фиолетовая, контурная, жёлтая,
  фиолетовая-градиент) — неясно, что главное. «✂️» — цветной эмодзи в главной кнопке.
