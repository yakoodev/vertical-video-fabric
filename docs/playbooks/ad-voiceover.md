# Реклама сайта/товара с озвучкой

Вертикальный ролик 25–45 с про сайт, магазин или товар: страницы сайта слоями, голос за кадром, субтитры по
голосу, музыка под голосом, финал с логотипом и промокодом. Записей экрана нет — нужен только сайт.

## Шаги

1. **Бриф.** `get_project_brief(project_id)` — лор, правила, `narrator_voice` (голос рассказчика проекта:
   Витубика — Aoede). Голоса нет — выбери по описанию `tts_preview` (пол, тембр) и дай владельцу послушать
   `tts_preview(text: первая фраза, voice)`.
2. **Сайт.** `web_search` → официальный сайт → `page_snapshot` главной, товара и цен → `page_edit` (подсветка,
   убрать баннер, `crop_to` цены) → `page_to_layers` для ключевого экрана (фон и блоки отдельными слоями).
   Ссылку у владельца не спрашивай, пока поиск что-то находит.
3. **Текст** — 5–8 фраз, каждая до ~200 знаков, всего 25–45 с речи. Разговорно, «как другу», без ярлыков
   капсом и без обещаний (суммы бонусов в текст не выносить). Бренды и латиницу: `text` — как показать в
   субтитрах («Live2D», «Free10»), `say` — как прочитать («лайв-два-дэ», «фри десять»).
   **Без style**: Gemini зачитывает любое указание к речи вслух — характер задаёт выбор голоса.
4. **Холст.** `create_canvas_clip(project_id, duration: 30)` — длину потом подгонит озвучка.
5. **Голос — одним вызовом:** `add_voiceover(clip_id, lines: [{text, say?}, …], voice?, tail_sec: 3)`
   (`tail_sec` — финал с логотипом после последнего слова).
   - Каждая фраза синтезируется отдельно (бесплатный Gemini), Whisper сверяет её с текстом.
   - Слои `vo_N`: `role: voice`, `mode: track`, `end` = длина файла, подряд с паузой 0.35 с
     (своя пауза — `pause_after` у фразы, своё место — `start`).
   - Холст удлиняется под голос; субтитры — текст на времени настоящих слов (`caps_vo`, если субтитров не было).
   - В ответе: `table` (начало/конец/длина фраз), `lines[].speech` — где звучат слова, `verdict` проверки.
   - Переделать — тот же вызов с `replace: true`. Платный голос (polza) — только оценка, синтез по «да»
     владельца (`confirm`).
6. **Проверка голоса:** `check_voiceover(clip_id)` должен сказать «озвучка в порядке». Каждая находка — с `fix` и
   `fix_call {tool, args}`: обрезанный слой — `update_layer` end, зачитанный style или не тот текст —
   `add_voiceover(replace: true)`, дыра в голосе — сдвинуть фразу, субтитры мимо — `snap_subtitles_to_speech`.
7. **Визуал под фразы** — по `lines[].speech`: на каждую фразу свой экран сайта (слой page / блоки
   `page_to_layers`), наезд камерой на цену, кнопку, карточку товара; титр 2–5 слов из самой речи.
   Финал ≥ 3 с после последней фразы: логотип + промокод крупно (если голос кончился раньше — финал
   держится на тишине с музыкой, это нормально; дольше ~4 с без голоса — сократи холст `trim_piece`).
8. **Музыка:** `list_music` → `set_music(track_id, start_sec: energy_start_sec)` → `auto_mix` →
   `audio_mix_report`: голос над музыкой ≥ 12 дБ во время речи (`check_voiceover` скажет то же).
9. **Сдача:** `lint_clip` (группа voice входит) → `render_clip` → `render_status(render_id, wait_sec: 30)` до
   `done`. В ответе `voice` — «озвучка с ошибками: …» значит файл есть, но сдавать нельзя: поправь по
   `check_voiceover` и перерендерь. Потом `lint_clip` по файлу (вспышки, луп), `contact_sheet`, `listen` на
   концовке — что слышно = что написано.

## Инструменты MCP

`get_project_brief`, `web_search`, `page_snapshot`, `page_edit`, `page_to_layers`, `tts_preview`,
`create_canvas_clip`, `add_voiceover`, `check_voiceover`, `add_layers`, `update_layer`, `set_camera`,
`list_music`, `set_music`, `auto_mix`, `audio_mix_report`, `lint_clip`, `render_clip`, `render_status`,
`contact_sheet`, `listen`.

## Чего не делать

- `tts_preview` + `add_layers` audio вручную без `end` и `role` — так получались фразы по 3 с, учтённые как эффект.
- Весь текст одной пробой: длиннее 1000 знаков `tts_preview` откажет; длинная фраза хуже ложится под кадры.
- `style` / «говори бодро» — модель прочитает это вслух первыми словами ролика.
- «Готово» до `render_status` со `status: done` и без «озвучка в порядке».

## Чек-лист перед сдачей

- [ ] `check_voiceover` — «озвучка в порядке»: нет лишних слов в начале, нет обрезанных фраз, тишина внутри
      голоса не дольше 1.2 с, голос покрывает ролик, голос ≥ 12 дБ над музыкой, субтитры совпадают с голосом.
- [ ] `render_status` — `status: done`, `voice_ok: true`.
- [ ] Финал: логотип и промокод держатся ≥ 3 с, не под кнопками площадок (`lint_clip` ui_zones).
- [ ] Текст живой, без обещаний и ярлыков; всё, что сказано, есть на экране или в субтитрах.
- [ ] `contact_sheet` — на каждую фразу свой экран сайта, ничего не пустует.
