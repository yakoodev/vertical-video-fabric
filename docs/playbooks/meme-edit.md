# Мем-эдит игры (геймплей под музыку + видеомемы)

Быстрый эдит из одной записи игры, как реф владельца (`D:\vvf-offload\memes\ref_37872`): геймплей рубится по
долям музыки, на каждом моменте — врезка видеомема со своим звуком, удар камерой, вспышка, синий негатив на главном
моменте, 2–4 жёлтых мультяшных слова. Одним вызовом `meme_edit` — два новых клипа: 9:16 и 16:9.

## Когда

Владелец просит «мем-эдит», «эдит под музыку с мемами», «нарезку как в рефе» из записи игры (Apex и т.п.).
Не для разговорных стримов и не для рекламы заказчика — там свои плейбуки.

## Шаги

1. **Мемы.** `search_video_memes(tag: "шок")`, `"победа"`, `"фейл"`, `"смех"` — нужны одобренные владельцем
   (неодобренные эдит не берёт). Мало мемов — мало врезок: на каждое событие свой мем, без повторов. Не хватает —
   скажи владельцу, какие теги пустые.
2. **Музыка.** `list_music` → `music_track_id` (энергичный трек 110–150 BPM) или звук из библиотеки `music_asset_id`.
   Без них берётся трек с темпом ближе к 128 BPM.
3. **Сборка.** `meme_edit(source_id, music_track_id, target_sec: 30–60)`. Сначала можно `dry_run: true` — план без
   клипов (окна, мемы, слова). Свои моменты — `events: [{t, kind}]` (секунды исходника; kind: knock, kill, death,
   squad_wipe, win, reaction, teammate_fail…), иначе детектор игры, а без него — по звуку (пик перестрелки = «нок»,
   громкий голос = «реакция»). Другой вариант — `seed`.
4. **Проверка.** `render_status` у обоих клипов → `contact_sheet` (врезки мемов, слова не в первые 2.5 с, негатив) и
   `listen` на мемах: мем слышно, игры под ним нет. Субтитры — только на фразах-реакциях и моментах.
5. **Правки** — обычными инструментами клипа: другой мем — `remove_insert` + `place_video_meme`; слово —
   `update_layer`; склейки — `apply_cuts`; музыка — `set_music`. Вертикаль и горизонталь — разные клипы: правь оба.

## Что делает сервис сам

- склейки в долю: окна по целому числу долей, музыка стартует с сильной доли; событие — ровно на долю;
- события → теги мемов: килл/нок → победа, шок; смерть → фейл, грусть; тиммейт → тиммейт; реакция → смех;
- мем во весь кадр (`render.inserts`, full, мем вровень с голосом), до 4 с; вшитые чёрные поля срезаны, подрезка
  под кадр вокруг лица до 45 %, дальше — размытая копия вокруг;
- под мемом игра и микрофон молчат, музыка играет на 8 дБ тише;
- серый экран смерти/зрителя: там нет «нока» — это смерть (мем фейл/грусть); рубка — не в первые 5 с, не на
  сером экране и не на кадрах без движения;
- наезд с тряской на попаданиях, вспышка (до трёх), негатив `#6fa8ff` + удар басом на главном моменте;
- слова «мульт-жёлтый» (Dela Gothic One, жёлтый, толстая обводка, прыжок, наклон) — `app/meme_edit_text.py`, в
  редакторе — «Текст → Мульт-жёлтый»;
- звук записи: игра + микрофон (авто-громкость), шумодав микрофона, мат — серединой слова со звёздочками;
- в начале текста нет, стоп-кадра в конце нет (`end_hold 0`).

## Инструменты MCP

`search_video_memes`, `list_music`, `meme_edit`, `render_status`, `contact_sheet`, `listen`, `place_video_meme`,
`remove_insert`, `update_layer`, `apply_cuts`, `lint_clip`.

## Чек-лист перед сдачей

- [ ] Каждый мем по смыслу момента и не повторяется; на мемах слышно мем, не игру.
- [ ] Склейки в долю (на слух: рубка идёт с битом), нет обрывков фраз в микрофон без смысла.
- [ ] Слова не закрывают прицел и HUD-счёт, не в первые секунды; мата в звуке нет, в субтитрах — звёздочки.
- [ ] Оба формата отрендерены и просмотрены (`contact_sheet`), `lint_clip` без `warn` по вспышкам.
