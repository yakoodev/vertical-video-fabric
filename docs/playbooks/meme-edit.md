# Мем-эдит игры (лучшие бои записей под музыку + видеомемы)

Нарезка из нескольких записей игры, как одобрил владелец (пилот 2, `D:\vvf-offload\memes\pilot2\storyboard.md`):
каждый бой **целиком** — от первых выстрелов до конца и реакции, внутри вырезано только мёртвое время; видеомем —
сразу после реплики игрока и по её смыслу (лучше всего «эхо» его слова), ~1 на 20–25 с; все склейки, мемы и переходы
— в долю его песни; хайповые переходы со звуком. Одним `meme_edit` — фоном, итог — готовые ролики: горизонталь 16:9
до 5 минут и вертикаль 9:16 «лучшее» на 60–90 с из трёх сильнейших боёв.

Чего НЕ делать (владелец забраковал): рубку по 0.5–1 с, «только конец киллов без начала стрельбы», мемы на громкие
места, мем каждые 10 с, длинные мемы с паузами, голливудские мемы без попадания в смысл.

## Когда

Владелец просит «мем-эдит», «нарезку под музыку с мемами», «как пилот», «лучшее из записей» по игре (Apex и т.п.).
Не для разговорных стримов и не для рекламы заказчика — там свои плейбуки.

## Шаги

1. **Записи.** `list_projects` → id записей игры (горизонтальные, с двумя дорожками: 0 — игра и тиммейты, 1 —
   микрофон). Все записи проекта — `channel_project_id`.
2. **Мемы.** `search_video_memes` по словам, которые игрок говорит в этих боях, и по тегам (фейл, победа, шок,
   непонимание, кринж) — нужны одобренные владельцем. Мало мемов — мало врезок: скажи владельцу, каких не хватает.
3. **Музыка.** `list_music` → `music_track_id` песни владельца (он её выбирает сам).
4. **План.** `meme_edit(source_ids: [..], music_track_id, dry_run: true)` → `job_id`; `meme_edit(job_id)` до `done` →
   `plan`: какие бои взяты (`fights`: сила, итог, реплики), мемы (после какой реплики, эхо), переходы, швы музыки,
   `notes` (слабые бои, чего не хватило). Покажи владельцу список боёв и мемов, если он просил согласовать.
5. **Сборка.** Тот же вызов без `dry_run` → `job_id`; статус — `meme_edit(job_id)` (стадии: planning → blocks →
   rendering → concat → done; рендер по блоку на бой, минуты). Итог — `result.horizontal.clip_id` и
   `result.vertical.clip_id` — обычные клипы с готовым файлом (`video_url`).
6. **Проверка.** `contact_sheet` и `listen` по клипам-блокам (`blocks`): бой с начала стрельбы, мем сразу после
   реплики и по смыслу, мем короткий (удар), мата в звуке нет, субтитры игрока белые, тиммейтов голубые; на готовом
   ролике — склейки и переходы в такт, музыка тише под голосом и мемом.
7. **Правки.** Блок — обычный клип: другой мем — `remove_insert` + `place_video_meme`; слово — `update_layer`. После
   правок блока ролик собирается заново новым `meme_edit` (кэш событий, речи и склеек мемов — второй раз быстрее).

## Что делает сервис сам

- бои: события игры + стрельба по звуку + реплики; начало — первый контакт − 1.5 с, конец — после реакции игрока;
  мёртвое время > 3 с вырезано, переход на вырезе; слабые бои выкинуты целиком, начала боёв не режутся;
- порядок: быстрый понятный бой первым, победа последней, сильнейший разворот перед ней, победа/фейл через раз;
- мемы: только одобренные, без повторов, не больше двух на бой, после реплики (или в конце боя), эхо — первым;
  только удар мема 0.8–2.2 с без пауз и без мата мема (файл библиотеки не меняется — склейка в кэше);
- доли: сетка всего трека, концы кусков и мемы в долю (слово и начало стрельбы не режутся), трек короче ролика —
  повтор на такте под стыком блоков;
- переходы: зум-панч, глитч, вжух, RGB-сдвиг, тряска по кругу, вспышка на стыке актов, у каждого свой звук из пака;
  зум на плашках нок/вайп, синий негатив + бас на «ВЫ ЧЕМПИОН», 1 жёлтое слово-цитата на ~80 с;
- звук: шумодав микрофона, мат игрока серединой слова, мат тиммейтов целым словом, под мемом игра и микрофон
  молчат; музыка одной подложкой: под голосом −12 дБ, под мемом −16 дБ, тишина перед последней репликой и
  возврат на последнем меме; −14 LUFS.

## Инструменты MCP

`list_projects`, `search_video_memes`, `list_music`, `meme_edit`, `render_status`, `contact_sheet`, `listen`,
`place_video_meme`, `remove_insert`, `update_layer`, `lint_clip`.

## Чек-лист перед сдачей

- [ ] Каждый бой виден с первых выстрелов (дэмедж в начале не потерян), конец — с реакцией игрока.
- [ ] Мемов ~1 на 20–25 с, каждый по смыслу реплики, короткий, не повторяется; на мемах слышно мем, не игру.
- [ ] Склейки и переходы в такт песни; переходы разные; музыка не глушит голос.
- [ ] Мата в звуке нет, в субтитрах звёздочки; субтитры игрока и тиммейтов разного цвета.
- [ ] Оба ролика просмотрены (`contact_sheet` по блокам), ссылки на готовые клипы — владельцу.
