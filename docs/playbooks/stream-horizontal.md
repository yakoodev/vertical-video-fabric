# Горизонтальная нарезка стрима 10–15 мин (16:9)

Один ролик 16:9 на стрим: арка стрима по порядку, лучшие моменты подряд, 10–15 минут. К вертикалям
(плейбук `stream-shorts`) — «лучшее за стрим» для YouTube.

## Шаги

1. **Звук записи** — как в `stream-shorts`, шаг 1 (`set_source_audio`: голос над игрой, `speech_tracks`).
2. **Арка стрима.** `get_source_transcript`, `chat_activity`, `source_loudness` по всему стриму —
   выпиши кандидатов с таймкодами и разметь, где начало (с чем пришла, во что играет), развитие,
   кульминации, финал. Нужны те же **законченные моменты** (завязка → пик → реакция), но длиннее:
   30–120 с, с контекстом между ними.
3. **Отбор.** Лучшие моменты **по порядку стрима** (хронология — это и есть арка), суммарно 10–15 мин.
   Слабые и повторы выкидывай; связку между моментами — короткую (5–15 с), только если без неё
   непонятно, что поменялось.
4. **Клип.** `create_clip(project_id, title, pieces)` — до 12 кусков, каждый до 180 с, по хронологии.
   Больше кусков нужно — длинные паузы внутри кусков режь `apply_cuts`, а не дроби на куски.
   Длинные тёмные меню паузы — сокращать так же, как в шортсах.
5. **Формат.** `set_format("16:9")` — тот же монтаж в 1920×1080; раскладка split сама становится окошком
   вебки в углу (docs/AGENTS.md, «Форматы вывода»). `view_frame` — окошко не закрывает интерфейс игры.
6. **Переходы.** `set_transition(type: "fadeblack", duration: 0.3…0.5)` между кусками — «прошло время»;
   `fit_speech: true`, чтобы наплыв не съел слова.
7. **Субтитры** — по желанию заказчика; если включены — внизу (`set_subtitles`), сверка с речью как в
   шортсах. TTS чата — «чат:».
8. **Мат** можно **не глушить**, если площадка позволяет (обычный ролик YouTube); канал для детей,
   реклама или просьба заказчика — глушить как в `stream-shorts`, шаг 6 (`censor_profanity`, если есть).
9. **Плашка канала** — `set_nameplate(platform, handle, position: "top-left")`. Правый нижний угол
   16:9 не занимать — там водяной знак YouTube.
10. **Рендер** — `vvf.py render <clip>`; замечание QC «длиннее 3 минут» для 16:9 не ошибка (это не Shorts).

## Инструменты MCP

`set_source_audio`, `get_source_transcript`, `chat_activity`, `source_loudness`, `source_contact_sheet`,
`create_clip`, `trim_piece`, `apply_cuts`, `set_format`, `set_layout`, `set_transition`, `set_subtitles`,
`generate_subtitles`, `set_subtitle_words`, `censor_profanity` (если есть) / `mute_audio`,
`set_nameplate`, `contact_sheet`, `listen`, `view_frame`.

## Чек-лист перед сдачей

- [ ] Длина 10–15 мин; моменты по порядку стрима, каждый законченный.
- [ ] `contact_sheet(n: 24)` — нет чужого контента: песен со словами, чужих видео и превью, фото
      реальных людей; нет длинных меню паузы и окон рабочего стола.
- [ ] Склейки: `listen` вокруг каждого стыка — слова не обрезаны переходом.
- [ ] QC: около −14 LUFS, пик ≤ −1.5 dBTP.
- [ ] Мат — по правилам площадки/заказчика (глушить или нет — решено явно).
- [ ] Плашка канала не в правом нижнем углу и не на интерфейсе игры.
