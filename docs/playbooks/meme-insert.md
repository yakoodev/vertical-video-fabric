# Мем или вставка поверх видео

Картинка-мем, гифка, видео-мем или скрин поверх клипа — ровно на слово, не закрывая видео. Правила
уже собраны в docs/AGENTS.md (почти все — в «Подводных камнях») — здесь порядок действий и ссылки.

## Шаги

1. **Где.** Момент — слово или реакция: `get_clip.subtitles` → номер строки/слова или `{text, nth}`.
2. **Что.** Мемы — `search_pack` (паки мемов, `list_packs`), картинки — `search_web_images` →
   `add_image_from_url`, свои — `upload_image`; видео-мем по ссылке владельца — `add_video_from_url`.
   Для нарезок стрима **без фото реальных людей** и без чужих видео (плейбук `stream-shorts`).
3. **Как.**
   - статичная картинка — слой `image` через `add_layers` с `at_word` (docs/AGENTS.md, «На слово, а не на
     секунду»);
   - гифка — слой `image` (анимированные GIF/APNG играют по кругу с прозрачностью, docs/motion/spec.md,
     «Анимированные картинки с альфой») или вставка `add_insert` (mode `pip`) — окошко само встанет между
     хуком и субтитрами;
   - видео-мем — `add_insert` (mode `pip`, со звуком) или слой `video` (`add_video_from_url` → asset_id);
   - много места под скрины — раскладка `meme` (`set_layout(mode: "meme")`), а не панель поверх кадра
     (docs/AGENTS.md, «Видео не закрывать», «Фоны»).
4. **Звук** — 0–2 эффекта на ролик, только настоящие записи (docs/AGENTS.md, «Подводные камни» → «Звуки»).
5. **Проверка** — `view_frame` на вставке и `contact_sheet`; после рендера — `lint_clip`: стикер не под
   кнопками справа, подпись мема успевают прочитать, мигание не чаще 3 в секунду; мему под повторы —
   оценка `loop` (подсказки: `set_end_hold(0)`, подрезать хвост).

## Инструменты MCP

`get_clip`, `list_packs`, `search_pack`, `search_web_images`, `add_image_from_url`, `upload_image`,
`add_video_from_url`, `add_layers` (с at_word), `add_insert`, `set_layout`, `view_frame`, `contact_sheet`,
`lint_clip`.

## Чек-лист перед сдачей

- [ ] `lint_clip` по свежему рендеру — нет `warn` (зоны площадок, темп чтения, вспышки).
- [ ] Вставка ровно на слово/реакцию, держится, пока её успевают прочитать (≥ 0.6 с).
- [ ] Закрывает ≤ 40 % кадра и не лежит на лице, субтитрах, хуке (`add_layers` откажет при большем).
- [ ] Нет фото реальных людей и чужих видео там, где заказ это запрещает.
- [ ] Звук вставки не громче голоса.
