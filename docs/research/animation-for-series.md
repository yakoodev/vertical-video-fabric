# Анимация для аниме-сериала: короткая версия

21.11.2026. Полная версия с таблицами и ссылками: `D:\vvf-offload\anime3d\animation_research.md`.
Сериал: горизонталь, серии по 10 минут, VRoid/VRM (J_Bip_*), Blender 4.5, наши NPR-шейдеры. Герои: сутулый
депрессивный парень и сёрф-панк группа (гитара, бас, барабаны). Пометки: [проверено] — первоисточник прочитан,
[вторично] — по поиску/прошлым ресерчам, [вывод] — моё заключение.

## TL;DR
1. **Мокап для публикаций, бесплатно**: Quaternius (CC0, уже скачан), **100STYLE** (CC BY 4.0, есть стили Depressed,
   Old, HandsInPockets, Strutting, LeanBack; BVH 1.5 ГБ) [проверено], CMU (свободно) [вторично], Rokoko 263 клипа
   (коммерция да, нужна почта) [проверено], Mixamo (коммерция да, нужен Adobe ID владельца) [вторично].
   **Нельзя**: Bandai Namco (CC BY-NC 4.0) [проверено], AIST++, AMASS, LaFAN1, ActorCore (мутно).
2. **Инструменты**: бесплатного мокапа игры на гитаре/басу/барабанах нет. Делаем **процедурно по звуку**:
   demucs → дорожки → удары бочки/малого/тарелок, ноты баса, темп → палки, педаль, щипки, бой, кивки в бит.
3. **Видео → движение, законно**: **NVIDIA GEM-X** (код Apache-2.0, веса NVIDIA Open Model License «Models are
   commercially usable») [проверено]; Linux → WSL. GVHMR некоммерческий [проверено]; WHAM/TRAM/HMR2 (SMPL),
   HaMeR/WiLoR (MANO, NC-ND) — нет.
4. **Текст → движение**: **NVIDIA Kimodo** (коммерция да для SOMA-моделей) [проверено], но нужен Llama-3 8B по заявке и
   много памяти — на потом. HY-Motion 24–26 ГБ видеопамяти — не влезает. MoMask/MDM — только эскизы.
5. **Главное — слои поверх любого движения**: прибивка стоп, сокращение до поз + усиление + задержки, двойки/тройки по
   планам со ступенями от событий (удары и контакты на показанных кадрах), дыхание, шум, взгляд глаза → голова → грудь,
   моргание и саккады, наши пружины волос, позы кистей, мимика 0.8–1.0, рот тремя положениями по словам Whisper.

## Аниме-вид
- Guilty Gear Xrd: ограниченная анимация, кадры убраны специально, без интерполяции [вторично].
- Orange (Lustrous, Beastars, Trigun Stampede): кадров меньше среднего, частота меняется по задаче («три кадра в
  секунду выглядит мягко»), 2D-мимика на крупных планах, голос записан до анимации [проверено: ANN, Slashfilm].
- У нас: Stepped Interpolation на действие арматуры (двойки — разговор/ходьба, тройки — медленное/группа, единицы — быстрые
  удары), камера на единицах, смазы и размножение палок, ударные кадры, экономные камерные приёмы.
