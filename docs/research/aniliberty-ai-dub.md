Разбор ИИ-озвучки AniLiberty.

Кто: по всему, что нашёл, это не сама команда AniLiberty, а отдельный фанатский проект AiLiberty (ailiberty.top / ailiberty.tv, ТГ @ailiberty_tv). В их FAQ: некоммерческий проект одного энтузиаста, нейросеть обучена на собранной базе озвучек AniLiberty и имитирует голоса актёров, с упором на интонации и темп. Тайтлы, которые студия не озвучивала, получают «её» голоса. Сайт, по их словам, собран с помощью Cursor и Claude. Канал Neurogen называет его пиратской платформой, но звучит, говорит, неплохо. Согласия актёров нигде не видно.

Модели они не называют. Конвейер такого типа почти наверняка устроен так (это мой вывод, не их слова):
1. Архив старых серий → demucs/UVR отделяет голос от музыки и эффектов.
2. Голоса режутся по репликам и раскладываются по актёрам: тайминги из субтитров + распознавание диктора.
3. На каждого актёра — своя модель голоса: GPT-SoVITS, F5-TTS или Fish Speech (сотни часов на актёра, качество высокое), или TTS + RVC поверх.
4. Текст — готовые русские субтитры (фансаб или машинный перевод с правкой LLM). Каждая реплика синтезируется с эмоцией по образцу похожей реплики того же актёра и подгоняется по длине под тайминг субтитра.
5. Сведение поверх оригинальной дорожки без японского голоса (тот же demucs).

Почему звучит круто: у них сотни часов чистого голоса каждого актёра в одной манере — это главное. Нам это пригодится для своих персонажей: эмоции по образцу и подгонка под тайминг у нас уже частично есть (голоса в субтитрах, Gemini делит голоса).

## Дополнение (20.11, вечер)
Докопал, что смог. Их сайт и ТГ с ПК не открываются, поэтому тянул через поиск по кэшу их FAQ.

Что у них:
— AiLiberty, раньше TheBestAiPortal (2024). Один человек, бесплатно, выпускает «когда есть время».
— Главное: восстанавливает ЗАБЛОКИРОВАННЫЕ релизы AniLiberty. Часть релизов берёт через официальный API AniLiberty.
— Модель обучена на собранной базе озвучек AniLiberty и имитирует голоса актёров дубляжа.
— Каждая серия: «анализ реплик → синтез речи → постобработка».
— Железо: одна RTX 4090, Ryzen 9 7950X, 128 ГБ ОЗУ. Значит, всё локально, без облака: открытые модели, дообученные на голосах.
— Архитектуру не называют («современные архитектуры глубокого обучения»).

На одной 4090 при таком качестве это почти наверняка GPT-SoVITS (v2pro/v4) или F5-TTS / Fish Speech, дообученные на каждого актёра. Обучающие данные — их же серии: голос отделён от музыки (UVR/demucs) и порезан по субтитрам.

Что можем сами: у нас RTX 4070 Ti (12 ГБ), на дообучение GPT-SoVITS хватает. Могу собрать пробу: голос персонажа с 10–30 мин чистой речи → реплики с эмоциями под тайминг субтитров → сведение с музыкой. Нужно скачать GPT-SoVITS с предобученными весами (~5 ГБ, GitHub + HuggingFace) и выбрать, чей голос (свой или с разрешением). Качать?
