# Лицо у 3D-персонажей VRM: готовые модели, данные и автоматика

Дата ресерча: 12.11.2026. Для владельца, простым языком. Код не менялся.

Задача: у наших бесплатных моделей (three-vrm-girl, Seed-san, VRM1_Constraint_Twist_Sample) мало выражений лица, лицо деревянное или дёргается. Своё лицо на видео владелец снимать не будет, поэтому ищем готовое: модели, данные, библиотеки.

## Коротко, что такое «perfect sync» и почему это главное

У обычной VRM-модели есть примерно 5 эмоций (радость, злость, грусть, удивление, спокойствие), 5 гласных для рта и моргание. Это всё. Между ними лицо «щёлкает».

«Perfect sync» это модель, у которой есть 52 отдельные «ручки» лица по стандарту Apple ARKit: левая бровь вверх, правый уголок рта вниз, прищур, раздувание щёк, язык и так далее. Из таких ручек можно собрать любое выражение плавно, а ещё их выдают готовые нейросети «звук в лицо». Без модели с этими 52 ручками никакой дорогой анимацией лицо не оживить. Поэтому первый шаг почти всегда: заменить или доделать модель.

Как читать таблицы:
- **Лицензия для коммерческих видео**: да / нет / неясно. Ключевая строка цитируется. Если первоисточник прочитать не удалось, написано прямо.
- **Сложность подключения** к нашему конвейеру (node/vrm, three.js + three-vrm 3.x, headless, покадровый рендер): низкая / средняя / высокая. Сейчас в `node/vrm/src/avatar.ts` лицо управляется пресетами `happy, sad, angry, surprised, aa, ih, ou, ee, oh, blink` через `expressionManager.setValue`. Для 52 ручек нужно только чтобы у модели такие выражения существовали, а код будет ставить их так же.

## Рекомендуемый путь (по убыванию отдачи на усилие)

1. **Сначала модель.** Взять бесплатные `hinzka/52blendshapes-for-VRoid-face` (коммерческое использование прямо разрешено, ссылка на автора не нужна). Это даёт 52 ручки лица сразу и бесплатно. Параллельно отдать на заказ (или сделать через HANA_Tool, около 10 долларов + Unity) perfect sync для тех героев, которые уже «в кадре». Платные модели с BOOTH брать только свои оригинальные, с письменным подтверждением права на видео и рекламу, и не по франшизам.
2. **Затем рот и мимика от звука: Wav2ARKit** (Apache-2.0, процессор, без видеокарты). Озвучка проходит через модель заранее, получаем кривые 52×кадры на каждую реплику и кладём в JSON рядом с клипом. Покадровый рендер просто читает значение для кадра.
3. **Эмоции и характер: один раз составить «библиотеку эмоций»** из 12-15 наборов ARKit (радость, злость, грусть, удивление, смущение, усмешка, сомнение, усталость и т.д.) с мягкими переходами. Теги эмоций расставляет сценарий (у нас уже есть языковая модель). Это единственное, что готовыми данными закрыть нельзя, и это один файл.
4. **Слой «живости»**: автоморгание парами, микросакады глаз, лёгкая случайная асимметрия бровей и уголков рта на 1-3 процента, «дыхание» лица. Писать самим, по образцу AIRI/Amica (MIT).
5. **Склейка слоёв**: итоговое значение каждой ручки = эмоция + рот от Wav2ARKit + живость, с ограничением 0..1 и приоритетом рта над эмоцией в зоне челюсти (чтобы улыбка не «съедала» гласные).

### Конкретные следующие шаги

1. Скачать оба `.vrm` из hinzka, загрузить в наш `node/vrm` и вывести список `expressionManager.expressions` (в `main.ts` это уже есть). Проверить, что есть имена вроде `BrowInnerUp`, `JawOpen`, `MouthSmileLeft` и в каком регистре они лежат (у VRM 0.x имя выражения берётся из имени клипа, регистр важен).
2. Сделать одну тестовую 5-секундную сцену: фраза озвучки, Wav2ARKit, рендер, показать владельцу рядом со старым результатом.
3. Если результат нравится: переписать `avatar.ts` так, чтобы ручки ARKit ставились списком `{имя: значение}` покадрово (сейчас набор зашит в 13 имён `EXPR`).
4. Составить файл «эмоции» (12-15 штук) и тест перехода «нейтрально, радость, удивление, грусть».
5. Для остальных героев (три текущие модели): либо заказ/HANA_Tool, либо заменить на модели с perfect sync. Решение за владельцем после шага 2.

## Чего лучше не брать

- **EmoTalk** (CC-BY-NC, только некоммерческое) и любые датасеты BEAT/3D-ETF/myned-ai MediaPipe (NC).
- **AITuberKit версии 2.0 и выше** (нужна коммерческая лицензия).
- **Модели по чужим франшизам** (Jinx, Huntrix и подобные) и любые модели без письменного права на коммерческое видео.
- **MetaHuman / MetaHuman Animator** для наших VRM: право на лицевые анимации вне Unreal спорное, нужна консультация; выгоды против Wav2ARKit мало.
- **NVIDIA Audio2Face-3D** сейчас: лицензия весов с индемнити, нужна видеокарта NVIDIA и TensorRT, 52-ARKit выход не подтверждён. Вернуться, только если Wav2ARKit покажется слабым.
- **Rokoko и любой мокап своего лица** (владелец отказался).
- **SadTalker и подобное**: делает 2D-видео из картинки, не 3D-мимику.
- **NeuroSync**: можно, но тяжёлее, пока Wav2ARKit проще; не использовать его 7 «эмоциональных» каналов.
- **Платная нейро-озвучка и платный шлюз** в этой задаче не нужны.
