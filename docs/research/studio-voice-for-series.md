## Рекомендация

1. Играет живой человек. Прошлый пилот (ESpeech, голос из 10-секундного образца) забраковали за отсутствие игры:
   крик на октаву ниже, шёпот не шёпот [наш замер]. С русским ни одна TTS стабильно не играет как актёр. У ElevenLabs v3
   теги эмоций срабатывают через раз [проверено].
2. Героя (60–70 % серии, внутренний монолог) озвучивает живой актёр своим голосом, без ИИ.
3. Остальных персонажей играют 1–2 актёра (мужчина и женщина), тембр меняем через S2S: Seed-VC f0 44 кГц (интонацию
   сохраняет почти один в один, совпадение 0,97–0,99 [наш замер]) или RVC на данных донора.
4. Тембры свои: 4–6 платных доноров голоса, у каждого 30–60 мин записи по договору с правом на ИИ-модель. Чужие голоса
   без согласия не клонируем. Голос владельца на паузе.
5. Другие языки: на крупные рынки — живой актёр на языке плюс те же тембры; на мелкие — облачный дубляж ($5–22 за серию
   и язык у ElevenLabs [проверено]).
6. Музыка: заказ у живой панк-группы с выкупом прав или своя группа; лицензии напрямую с белым списком канала в
   Content ID; CC-каталоги только с сохранённой лицензией.

## Ключевые факты

- ElevenLabs: Россия в списке заблокированных стран [проверено]; работать можно только с аккаунта владельца в Грузии.
  Creator $22/мес, около 100 тыс. знаков, это примерно 3 серии с перегенерациями. PVC от 30 мин, оптимум 2–3 ч, пение
  не поддерживается. Voice Changer — 1000 кредитов или $0,12 за минуту [проверено].
- IndexTTS2 — только китайский и английский. Fish S1-mini и S2 — открытые веса только для некоммерции. Hume сворачивает
  TTS [проверено].
- Яндекс Brand Voice Lite: $75 плюс $833 в месяц за каждый голос. Сбер YourVoice — по заявке [проверено]. Для сериала
  слишком дорого.
- Россия: отдельного закона о голосе нет, законопроект 718834-8 не поддержан правительством. Голос — биометрия, нужно
  письменное согласие (ст. 11 152-ФЗ); защищена запись исполнения (ст. 1315 ГК). Дело Андроновой против Тинькофф
  показывает, что согласие на ИИ-модель надо писать прямыми словами [проверено].
- Ставки русского фандаба публично не найдены. Прикидка: сессия актёра 3–6 тыс. ₽ в час, на серию 8–20 тыс. ₽, доноры
  разово 30–90 тыс. ₽ [оценка]. Перед решением запросить цены у 3–5 актёров.

## Проба на нашем ПК (без загрузок)

Текст: монолог около 60 с, панк-выкрик, шёпот (в полной версии). Сравниваем: A — ESpeech по образцу (якорь снизу),
B — лучшая локальная TTS с управлением подачей (CosyVoice3, VoxCPM2 или Chatterbox), C — Seed-VC f0 плюс
восстановление динамики, C2 — RVC, когда будет окно памяти, R — скрытая живая запись. Исполнитель-заглушка — наши
записи ElevenLabs; решающая проба — час нанятого актёра по договору. Метрики: CER, похожесть на тембр, совпадение
высоты и громкости с исполнением, доля пауз. Слепой тест: оценки 0–100 «студийно» и «это этот персонаж», всё на −16 LUFS.
Загрузки по желанию: UTMOSv2, около 1 ГБ.

## Главные риски

Одна манера у всех персонажей одного актёра; крик и смех после S2S; память ПК для обучения; лицензии моделей
(Seed-VC GPL, некоммерческие веса); ElevenLabs только из Грузии; без договора нет голоса.
