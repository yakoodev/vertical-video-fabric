4. Переходы: хлыст, заливка цветом, смена через размытие, затемнение в 3 кадра, шейдерные; сверка направления на стыках.

## Набор 3 (18.11): ghost-editor, OpenMontage, openmotion, youtube-agent-skill

- kurbaitaev/ghost-editor (MIT): выбор лучшего дубля фразы (распознавание кусков между паузами, нечёткое сравнение со сценарием, «поздняя чистая попытка», повторная проверка нарезанного), субтитры мимо лица по каждой странице с учётом зума, лимиты частоты (лицо ≥ 65 %, полноэкранная графика ≤ 25 %, ≤ 3 вставок/мин, мемный звук не повторять, не брать элементы последних 7 роликов стиля).
- OpenMontageInc/OpenMontage (AGPL — только идеи): разбор референса в рецепт (крючок, темп, каждый план по 5 пунктам, «на чём держится» + «чем отличаемся»), проба 10–15 с до полного.
- nexu-io/openmotion (Apache-2.0): формат Motion.md «время | решение | содержание»; бренд с сайта по ссылке (у gateway/brand-capture своя лицензия — читать перед переносом).
- Jakeschincariol/youtube-agent-skill (MIT): 21 формула крючка, оценка 0,6×среднее + 0,4×худшее по 5 качествам, правила названия (≤ 60 симв.) и обложки (≤ 3 слова, не повторяет название), шортсы с точкой зацикливания. Конфликты: формат мувиков владельца, приманки, суммы в промо, длинные описания.
Топ: дубли фраз → оценка крючка/пары название+обложка → референс→рецепт → лимиты частоты; пятым — субтитры мимо лица.
