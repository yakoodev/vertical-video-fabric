Движок не меняем: кадр как функция времени, превью = рендер, реакция на звук, размытие в движении, проверки зон/чтения/вспышек у нас уже есть. Берём:

1. Правила движения и монтажа в промпты агентов (owner_rules, frag-movie, explainer, app-promo, handoff): кадр 0 — крючок; резать на самом быстром кадре движения, одно направление по обе стороны склейки; пауза 0,3–0,75 с перед ответом у совы; строка 0,5 с + 0,3 с/слово; без «дыхания» титров; выход на 40–50 % короче входа; не масштабировать с 0; без штампов в промо; переводчик жалоб владельца в правки.
2. Проверки перед сдачей: пустой кадр 0, >3 с без изменений, полоски кадров вокруг склеек, лист 360 px, файл утверждений.
3. Пословные входы титров (из размытия, из серого в цвет, слот-машина, по буквам) + «один вход не повторять».
4. Переходы: хлыст, заливка цветом, смена через размытие, затемнение в 3 кадра, шейдерные; сверка направления на стыках.
5. Бас отдельной полосой для апекс-эдитов; рукописные пометки для совы.
