# Чего не хватает в сервисе

Приёмы из гайдов, которые нашими средствами сделать нельзя или можно только обходом. Польза:
★★★ — нужно почти в каждом ролике своего типа, ★★ — заметно поднимет часть роликов, ★ — приятно иметь.

| # | Чего нет | Зачем | Обход сейчас | Польза |
|---|---|---|---|---|
| 1 | ~~**Инструмент цензуры мата**: найти слова по словарю, заглушить середину на дорожке микрофона, звёздочки в субтитрах, проверка Whisper~~ ✅ `censor_profanity`, только голос — `track: "voice"` | правило владельца, делается руками по 2–4 круга на клип | — | ★★★ |
| 2 | ~~**Глушение одной дорожки** (`mute_audio`/`set_source_gain` по `track`)~~ ✅ `track` в отрезке | мат глушить только на микрофоне, игра звучит; шум игры убрать под фразой | — | ★★★ |
| 3 | ~~**Автоматизация музыки**: громкость по ключам, выключить на 0.3–0.8 с перед панчлайном, «стоп музыки» на шоке~~ ✅ `set_audio_keys`, `set_music_duck` (duck, dips) | тишина перед ударом — один из самых сильных приёмов | — | ★★★ |

| 11 | **Цветокоррекция по кускам** (экспозиция, баланс белого, подгонка кусков друг к другу) | компиляции и сериалы из разных сцен прыгают по цвету | один лук пресета на весь клип | ★★ |
