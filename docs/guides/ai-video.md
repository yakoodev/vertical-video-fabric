# ИИ-видео: серия с нуля (сценарий → референсы → кадры → видео → сборка)

Проект вида «ИИ-видео» (`projects.kind = ai_video`, модуль `ai_video`): ролик не нарезается из
источника, а рисуется. v2: план с `needs_motion` оживляет видеомодель (image-to-video 4–8 с со своим
фоновым звуком), склейки держит постоянство состояния, персонажи говорят своими TTS-голосами поверх,
субтитры и музыка — как у обычного клипа. План без движения — стоп-кадр с Ken Burns / 3D-камерой
(дешевле, запасной путь). Раскладка в 3D-движке — v3. Дизайн и цены —
[`docs/design/ai-video-projects.md`](../design/ai-video-projects.md).

## Деньги — главное правило

* Сценарий (Gemini), оценки, проверки постоянства и склеек, сборка — **бесплатно**.
* Голоса персонажей через Gemini TTS (`voice.provider: gemini`) — **бесплатно**: этап `voice` идёт
  сразу, без карточки.
* Картинки, видео и голос через провайдера (сейчас Polza) — **платно**. Агент их только **просит**:
  `aiv_request_approval` (этап) или `aiv_regenerate` (одна картинка/видео) кладут владельцу карточку
  с суммой (UI «Одобрение», баннер на вкладке «ИИ-видео», Telegram). Запуск — только после его
  «Разрешить». Одобрять, обходить карточку или «дробить», чтобы не заметили, нельзя. Инструмента
  «одобрить» у агента нет.
* Провайдер `none` — **сухой прогон**: вместо картинок заглушки, вместо видео — стартовый кадр с
  лёгким наездом и тихим тоном, вместо голоса тон; 0 ₽, карточки не нужны. Весь конвейер можно
  прогнать и проверить так.
* Потолки (сверх — отказ ещё при запросе, и повторная проверка перед каждым запуском):
  одна карточка ≤ `AIVIDEO_MAX_BUDGET_RUB` (2 500); серия ≤ 350 ₽ (черновик) / 2 500 ₽ (качество);
  месяц проекта (владелец ставит в стиле проекта) и месяц всех ИИ-видео (`AIVIDEO_MONTH_CAP_RUB`).
  Платная генерация вообще идёт только при `AIVIDEO_ENABLED=1` (включает владелец).
  **Серия с видео seedance почти всегда дороже 350 ₽** — её делают в режиме `quality`
  (`aiv_update_script quality`) или черновиком на `grok-imagine-video-1-5`; решает владелец.
* Цены (замер 2026-11-01, списание = прайс): видео `bytedance/seedance-2-fast` 720p **22.275 ₽/с**
  (план 4 с = 89.1 ₽), `grok-imagine-video-1-5` 720p **3.0375 ₽/с** (4 с = 12.15 ₽); картинка
  nano-banana 1K **3 ₽**, 2K **4.5 ₽**. Не замеренное — прайс ×2. Факт каждого запуска —
  `aiv_job_status` / журнал трат проекта.

## Провайдеры (подключаемые)

Провайдер — id + каталог (`app/aivideo_providers.py`, `CATALOGS`): таблицы цен картинок (₽/шт) и
видео (₽/с), замеры, лимиты моделей, сборка тела запроса и два адаптера с одним интерфейсом
(`submit` → id, `check` → статус, `fetch` → файл, необязательный `recover` — найти запрос, ушедший
без ответа). Проект выбирает провайдера и модель на этап: `provider` + `image_model` (картинки),
`video_provider` (пусто — как `provider`) + `video_model` + `video_resolution`. Сейчас есть `none`
и `polza`; kie.ai / fal.ai / Replicate / Veo — новый адаптер и каталог, конвейер не меняется.

## Порядок работы

1. **Проект и стиль.** `aiv_create_project(name, style_kind anime|photoreal, passport_text, palette,
   quality draft|quality, provider none|polza, video_model?)`. Стиль-паспорт — одна фраза, она идёт
   дословно в каждый промпт; одна модель картинок на проект (`image_model`, по умолчанию
   nano-banana-2.1), модель видео — `video_model` (по умолчанию `bytedance/seedance-2-fast` 720p со
   звуком; `grok-imagine-video-1-5` — дешёвый черновик без звука; `kling/v3` не берём — он сам режет
   план на склейки). Бриф, правила и табу проекта — как у сериалов (`get_project_brief`, `add_rule`).
2. **Персонажи.** `aiv_define_character(name, identity_card, voice?, origin?, speech?)`. Карта личности —
   возраст, волосы, глаза, рост и пропорции, 2–3 цвета hex, отличительная деталь; она вставляется в
   промпт ДОСЛОВНО (правка помечает картинки и кадры с персонажем «устарело»). Голос (TTS как в
   `dub_clip`):
   - `{provider: gemini, voice: Kore, style: "устало, медленно"}` — **бесплатно** (Gemini TTS по
     ключу сервиса; модель — `GEMINI_TTS_MODEL`, по умолчанию `gemini-3.8-flash-tts`). 30 голосов:
     Zephyr, Puck, Charon, Kore, Fenrir, Leda, Orus, Aoede, Callirrhoe, Autonoe, Enceladus, Iapetus,
     Umbriel, Algieba, Despina, Erinome, Algenib, Rasalgethi, Laomedeia, Achernar, Alnilam, Schedar,
     Gacrux, Pulcherrima, Achird, Zubenelgenubi, Vindemiatrix, Sadachbia, Sadaltager, Sulafat.
     `style` — как персонаж говорит (строкой перед репликой); смена `style` или голоса — реплики
     «устарели» и переозвучатся. Послушать до выбора — `tts_preview(voice, style, text)` (бесплатно,
     в ответе `url`).
   - `{provider: polza, model: elevenlabs/eleven-v4, voice: brian}` — платно, по карточке (без
     `provider` — тоже Polza: по умолчанию ничего не поменялось).
   - `{provider: none}` — сухой прогон тоном. Проект в сухом прогоне (`provider: none` у проекта)
     озвучивает тоном всех, какой бы голос ни был у персонажа.
   Свои витуберы/стримеры владельца — `origin: owner`, их картинки владелец загружает на вкладке
   «Персонажи» (они идут референсом в каждый лист и кадр). **Фото реальных людей из интернета не бери.**
   Облики по сюжету — `aiv_add_look(character, name, outfit_text, beat)`: меняется только одежда
   или состояние.
   **Кто не говорит словами** (робот, зверёк) — `speech: sfx`: его реплики станут звуками — настоящими
   записями пака freesound по `emotion` реплики (грусть — тромбон, злость — низкий удар, испуг — аккорд,
   удивление — хлыст, радость — поп, иначе мягкий поп; свой звук — `voice.sfx: "sfx:freesound/<файл>"`),
   0 ₽ и без TTS; `speech_captions` (по умолчанию да) — текст его реплик («Бип-бип?..») в субтитрах.
   `speech: none` — молчит, его реплики убираются из плана. «Не говорит» только в `notes` — мало,
   ставь `speech`: Gemini пишет сценарий по нему. В видео такие персонажи не «говорят ртом».
3. **Локации.** `aiv_define_location(name, description)` — на каждую одна «плита» фона 9:16.
4. **Сценарий.** `aiv_write_script(project_id, brief, duration_target)` — Gemini пишет шот-лист с
   `state` и `continues_from_prev` у каждого плана (см. «Постоянство склеек»), может сам завести
   недостающих персонажей/локации. Ответ — `warnings`: скачки позы/рук/одежды/реквизита между
   продолжающимися планами без действия — поправь действие или `state` (`aiv_update_shot`). Gemini
   недоступен — пиши сам `aiv_update_script(project_id, shots=[…], new_characters?, new_locations?)`.
5. **Референсы.** `aiv_estimate(stage refs)` → покажи сумму → `aiv_request_approval(stage refs)`:
   стиль (3 картинки настроения), плиты локаций, развороты и листы эмоций персонажей, облики. После
   «Разрешить» — `aiv_get_project`: версии, выбранная (`selected`). Не нравится —
   `aiv_regenerate(ref_id, note)`, другая версия — `aiv_select_version`.
6. **Кадры.** `aiv_estimate(stage keyframes, script_id)` → `aiv_request_approval(...)`. Кадры
   рисуются ПО ПОРЯДКУ. Референсы по важности (в лимит модели, у nano-banana 10): последний кадр
   прошлого плана (его видео) или его кадр — для склейки; ВСЕ листы персонажей в кадре (разворот +
   эмоции) и облик; плита локации; картинки владельца; стиль. Состояние плана — в промпте. Что ушло и
   чего не хватило — `params.ref_roles` / `params.missing_refs` запуска (`aiv_job_status`). План,
   который продолжает прошлый с видео, не рисуется (в `notes`: «кадр возьмётся из последнего кадра
   видео плана N», 0 ₽). Платный кадр с персонажами сам проверяется Gemini-зрением (бесплатно): ниже 6
   — версия `needs_review`, план в `aiv_get_script.needs_review` и бейдж «проверь» на раскадровке.
   Сама платная перерисовка НЕ запускается: покажи владельцу и, если он согласен, —
   `aiv_regenerate(ref_id, note)`. Перепроверить — `aiv_check_consistency(ref_id)`.
7. **Склейки.** `aiv_check_continuity(script_id)` (бесплатно, Gemini-зрение): стартовый кадр
   каждого плана против конца прошлого и заявленного `state`. Флаги — на раскадровке
   (`shot.continuity`). Перерисуй кадры с флагом (`aiv_regenerate target shot:ID` — 3–4.5 ₽) ДО видео
   (12–89 ₽ за план 4 с). Этап video запускает эту проверку сам и пишет флаги в карточку.
8. **Видео.** `aiv_estimate(stage video, script_id)` → `aiv_request_approval(stage video)`. Видео
   делается для планов с `needs_motion`, 4–8 с (не короче реплик плана), промпт — действие,
   `motion_prompt`, `state` (и конечное состояние, если следующий план продолжает этот), `sound`.
   Звук модели включён (`generate_audio`), речь — нет (её дают реплики). Сцепка: план с
   `continues_from_prev` после плана с видео стартует с ПОСЛЕДНЕГО КАДРА того видео (бесплатный
   шаг `chain`, ждёт, пока видео прошлого плана готово). Новое видео плана помечает сцепленный
   следующий план «устарело». Версии — `videos` в `aiv_get_script`, выбор — `aiv_select_version`,
   новая — `aiv_regenerate(ref_id видео или target shot:ID:shot_video)`.
9. **Озвучка.** Провайдер `none` — делается сама при сборке. Gemini (`voice.provider: gemini`) —
   этап `voice` **без карточки**, сразу (`aiv_request_approval(stage="voice")` → `status: done`, 0 ₽;
   лимиты бесплатного тарифа — сервис сам ждёт и повторяет). Polza — этап `voice` с карточкой
   (обычно копейки: ~0.005 ₽ за символ). Реплики `speech: sfx` — звуки пака, 0 ₽.
10. **Сборка.** `aiv_assemble(script_id, music_track_id?, captions_style?)` → НОВЫЙ холст-клип
    (`clip_id`). Дальше всё как с обычным клипом: `get_clip`, `contact_sheet`, правки слоями,
    рендер, `lint_clip`, `submit_for_approval`. Обрезать видео плана — `aiv_update_shot(video_in,
    video_out)` и собрать заново.

## Шот-лист (`shots`)

```json
{"duration": 4, "location": "kitchen", "needs_motion": true, "continues_from_prev": true,
 "characters": [{"id": "mira", "look": "pajamas", "action": "стягивает левый носок"}],
 "camera": {"shot": "medium", "angle": "eye", "move": "static", "lens": 35},
 "action": "Мира сидит на полу и стягивает левый носок",
 "motion_prompt": "тянет носок двумя руками, камера неподвижна",
 "sound": "шорох ткани, тихий гул холодильника",
 "state": {"characters": [{"id": "mira", "pose": "sitting", "facing": "camera", "position": "center",
                           "holding": "ничего", "clothing": "оба носка надеты"}],
           "props": [{"name": "носок", "state": "на левой ноге"}]},
 "dialogue": [{"who": "mira", "text": "Жарко…", "emotion": "tired"}],
 "image_prompt": "", "transition_in": "cut", "video_in": null, "video_out": null}
```

* `duration` 2–8 с (видео-план 4–8); реплики ~14 символов/с — длиннее, и видео сделается длиннее
  (до 8 с), а стоп-кадр удлинится.
* В кадре ≤ 2 персонажей (толпа — главный источник «другого человека»).
* `camera.move`: у видео — подсказка модели; у стоп-кадра `static` (лёгкое дыхание), `push_in`,
  `pull_out`, `pan_left|right`, `tilt_up|down` — Ken Burns слоя; `parallax_push`, `orbit`, `float`,
  `dolly_zoom`, `tilt_reveal` — 3D-камера на отрезке плана.
* `who` — id персонажа или `narrator` (закадр). `transition_in: fade` — наплыв с прошлого плана.
* У персонажа `speech: sfx` `text` — звукоподражание/ремарка, `emotion` обязательна (по ней звук);
  реплики `speech: none` убираются с предупреждением.
* `lipsync` — флаг на будущее; сейчас ни на что не влияет.

## Постоянство склеек

Владелец: «то персонаж сидит, то уже стоит, то уже повернулся — следи за этим». Поэтому:

* `state` — состояние на **начало** плана: по каждому персонажу в кадре `pose` (sitting / standing /
  lying / kneeling / walking…), `facing` (camera / left / right / away), `position`, `holding`,
  `clothing`; `props` — ключевой реквизит и его состояние. Состояние плана N+1 = состояние плана N,
  изменённое только тем, что показало действие плана N. Сервис сверяет соседние планы и пишет
  `warnings`; правка `state` делает кадр «устарело».
* `continues_from_prev` — та же сцена без скачка времени (по умолчанию да, если локация та же; у
  первого плана — нет). Такой план после плана с видео стартует с последнего кадра этого видео —
  совпадение по построению, без новой картинки. `false` — новый момент или резкая смена ракурса:
  кадр рисуется заново, но с последним кадром прошлого плана первым референсом.
* Перед этапом video — `aiv_check_continuity`: флаги не запускают ничего платного сами.

## Что получится в клипе

Слои `aiv_shot_N` (план с видео — `video` со звуком модели −4 дБ и стоп-кадром в конце; без видео —
`image` с кадром и движением камеры), `aiv_line_N_M` (каждая реплика — свой слой `audio` на своём
месте в плане), `aiv_captions` (субтитры из реплик с их окнами, стиль проекта), ключи камеры для
3D-планов, музыка проекта, приглушённая под репликами (`music_duck`). Склейки — по настоящим
длительностям видео. Холст — фон `solid` тёмный; каждая сборка — новый клип.

## Безопасность запусков

* Запуск берёт ровно один исполнитель (работник `aivideo-gen`, `aiv_run_approved`, другой процесс):
  `approved → submitting` одной транзакцией, `worker_id` — кто взял. `aiv_run_approved`, пока работник
  занят карточкой, повторно ничего не отправляет: взятое показывает в `in_progress`. Второй «готово»
  того же запуска не создаёт версию и не пишет трату. Звать `aiv_run_approved` «на всякий случай» не
  нужно — работник запускает сам сразу после «Разрешить».
* `remote_id` провайдера пишется в БД до опроса: после перезапуска опрос продолжается, второй
  POST (и вторая оплата) не уходит.
* Сеть до Polza рвётся. Сбой **до отправки** (`ConnectError` «TLS/SSL connection has been closed (EOF)»,
  `ConnectTimeout`) — повтор сам, до 3 раз с паузой: запрос не ушёл, денег не взяли. Не вышло —
  `failed` «не оплачено», «Повторить» без новой карточки (`aiv_retry_job`).
* Запрос **ушёл, а ответа нет** (`ReadTimeout`, обрыв, шлюз 502/503/504; у видеомоделей Polza POST
  отвечает 504 **всегда** через ~60 с, а работа идёт и списывается). Время отправки (`submitted_at`)
  пишется ДО POST. Адаптер умеет искать запрос у провайдера (Polza — `/history/generations`: та же
  модель, не раньше отправки, не занятый другим запуском) — статус `recovering`: нашёлся — опрос как
  обычно; POST **не повторяется никогда**, и после перезапуска поиск продолжается; не нашёлся за срок
  (картинка 5 мин, видео 20 мин) — `uncertain` «скорее всего не списано», повтор — `aiv_regenerate`.
  Адаптер искать не умеет — сразу `uncertain` со сверкой баланса до/после: не изменился — «Повторить»
  без новой карточки (`aiv_retry_job(job_id | approval_id)`, кнопка в баннере карточки); списано —
  трата в журнале (`balance`), повтор только `aiv_regenerate`; баланс не узнать — оценка держится в
  сумме карточки. Сеть не останавливает партию — остальные запуски идут; стоп — только деньги,
  политика, ключ (401/402/403) и непонятные сбои. Опрос/скачивание при сбое сети — позже, без POST.
* Ссылка на видео у Polza живёт 7 дней — файл скачивается сразу в «Файлы для монтажа».
* Одинаковый запрос (`input_hash`: модель, параметры, промпт, файлы референсов/стартового кадра)
  берёт готовый файл — 0 ₽. Перегенерация — всегда новая версия.
* Провайдер списал больше одобренного — партия останавливается (`held`), нужна новая карточка.
* Отказ контент-политики — `blocked_policy`: перепиши промпт плана (`image_prompt`, действие,
  `motion_prompt`) и попроси перегенерацию; не пытайся обходить модерацию.
