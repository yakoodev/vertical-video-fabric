# ИИ-видео: серия с нуля (сценарий → референсы → кадры → сборка)

Проект вида «ИИ-видео» (`projects.kind = ai_video`, модуль `ai_video`): ролик не нарезается из
источника, а рисуется. MVP — «моушн-комикс»: на каждый план один ключевой кадр, по нему едет камера
(Ken Burns или наша 3D-камера), персонажи говорят своими TTS-голосами, субтитры и музыка — как у
обычного клипа. Видеомодели (оживление кадров) — v2, раскладка в 3D-движке — v3. Дизайн и цены —
[`docs/design/ai-video-projects.md`](../design/ai-video-projects.md).

## Деньги — главное правило

* Сценарий (Gemini), оценки, проверка постоянства, сборка — **бесплатно**.
* Картинки и голос через Polza — **платно**. Агент их только **просит**: `aiv_request_approval`
  (этап) или `aiv_regenerate` (одна картинка) кладут владельцу карточку с суммой (UI «Одобрение»,
  баннер на вкладке «ИИ-видео», Telegram). Запуск — только после его «Разрешить». Одобрять, обходить
  карточку или «дробить», чтобы не заметили, нельзя. Инструмента «одобрить» у агента нет.
* Провайдер проекта `none` — **сухой прогон**: вместо картинок заглушки (градиент + подпись), вместо
  голоса тон, 0 ₽, карточки не нужны. Весь конвейер можно прогнать и проверить так.
* Потолки (сверх — отказ ещё при запросе, и повторная проверка перед каждым запуском):
  одна карточка ≤ `AIVIDEO_MAX_BUDGET_RUB` (2 500); серия ≤ 350 ₽ (черновик) / 2 500 ₽ (качество);
  месяц проекта (владелец ставит в стиле проекта) и месяц всех ИИ-видео (`AIVIDEO_MONTH_CAP_RUB`).
  Платная генерация вообще идёт только при `AIVIDEO_ENABLED=1` (включает владелец).
* Цены — прайс Polza ×2 (не замерено, как у озвучки). Факт каждого запуска — `aiv_job_status` /
  журнал трат проекта.

## Порядок работы

1. **Проект и стиль.** `aiv_create_project(name, style_kind anime|photoreal, passport_text, palette,
   quality draft|quality, provider none|polza)`. Стиль-паспорт — одна фраза, она идёт дословно в
   каждый промпт; одна модель картинок на проект (`image_model`, по умолчанию nano-banana-2.1).
   Бриф, правила и табу проекта — как у сериалов (`get_project_brief`, `add_rule`).
2. **Персонажи.** `aiv_define_character(name, identity_card, voice?, origin?)`. Карта личности —
   возраст, волосы, глаза, рост и пропорции, 2–3 цвета hex, отличительная деталь; она вставляется в
   промпт ДОСЛОВНО (правка помечает картинки и кадры с персонажем «устарело»). Голос —
   `{provider: polza, model: elevenlabs/eleven-v4, voice: brian}` (TTS как в `dub_clip`).
   Свои витуберы/стримеры владельца — `origin: owner`, их картинки владелец загружает на вкладке
   «Персонажи» (они идут референсом в каждый лист и кадр). **Фото реальных людей из интернета не бери.**
   Облики по сюжету — `aiv_add_look(character, name, outfit_text, beat)`: меняется только одежда
   или состояние.
3. **Локации.** `aiv_define_location(name, description)` — на каждую одна «плита» фона 9:16.
4. **Сценарий.** `aiv_write_script(project_id, brief, duration_target)` — Gemini пишет шот-лист
   (может сам завести недостающих персонажей/локации). Gemini недоступен — пиши сам
   `aiv_update_script(project_id, shots=[…], new_characters?, new_locations?)`. Правка одного
   плана — `aiv_update_shot`.
5. **Референсы.** `aiv_estimate(stage refs)` → покажи сумму → `aiv_request_approval(stage refs)`.
   Это стиль (3 картинки настроения), плиты локаций, развороты и листы эмоций персонажей, облики.
   После «Разрешить» — `aiv_get_project`: версии, выбранная (`selected`). Не нравится —
   `aiv_regenerate(ref_id, note)`, другая версия — `aiv_select_version`.
6. **Кадры.** `aiv_estimate(stage keyframes, script_id)` → `aiv_request_approval(...)`. В каждый
   кадр идут референсы: канон персонажей (+ облик), плита локации, стиль. Проверь постоянство —
   `aiv_check_consistency(ref_id)` (бесплатно; ниже 6 — перерисуй этот кадр).
7. **Озвучка.** Провайдер `none` — делается сама при сборке. Polza — этап `voice` с карточкой
   (обычно копейки: ~0.005 ₽ за символ).
8. **Сборка.** `aiv_assemble(script_id, music_track_id?, captions_style?)` → НОВЫЙ холст-клип
   (`clip_id`). Дальше всё как с обычным клипом: `get_clip`, `contact_sheet`, правки слоями,
   рендер, `lint_clip`, `submit_for_approval`.

## Шот-лист (`shots`)

```json
{"duration": 4, "location": "kitchen",
 "characters": [{"id": "mira", "look": "pajamas", "action": "открывает холодильник"}],
 "camera": {"shot": "medium", "angle": "eye", "move": "push_in", "lens": 35},
 "action": "свет холодильника на лице",
 "dialogue": [{"who": "mira", "text": "Опять пусто…", "emotion": "tired"}],
 "image_prompt": "", "transition_in": "cut", "lipsync": false}
```

* `duration` 2–8 с; реплики ~14 символов/с — длиннее, и при сборке план удлинится под голос.
* В кадре ≤ 2 персонажей (толпа — главный источник «другого человека»).
* `camera.move`: `static` (лёгкое дыхание), `push_in`, `pull_out`, `pan_left|right`,
  `tilt_up|down` — Ken Burns слоя; `parallax_push`, `orbit`, `float`, `dolly_zoom`, `tilt_reveal` —
  3D-камера на отрезке плана (мягче обычного: кадр плоский, сильный облёт показал бы край).
* `who` — id персонажа или `narrator` (закадр). `transition_in: fade` — наплыв с прошлого плана.
* `lipsync` — флаг на будущее (v2, только крупные планы); сейчас ни на что не влияет.

## Что получится в клипе

Слои `aiv_shot_N` (image, кадр плана), `aiv_voices` (одна дорожка всех реплик), `aiv_captions`
(субтитры из реплик с их окнами, стиль проекта), ключи камеры для 3D-планов, музыка проекта.
Холст — фон `solid` тёмный; каждая сборка — новый клип, правки прошлой сборки сохраняются в ней.

## Безопасность запусков

* `remote_id` провайдера пишется в БД до опроса: после перезапуска опрос продолжается, второй
  POST (и вторая оплата) не уходит. Запуск, оборванный между «отправляю» и ответом, сам не
  повторяется — статус `failed` с «проверь баланс».
* Одинаковый запрос (`input_hash`: модель, параметры, промпт, файлы референсов) берёт готовый
  файл — 0 ₽. Перегенерация — всегда новая версия.
* Провайдер списал больше одобренного — партия останавливается (`held`), нужна новая карточка.
* Отказ контент-политики — `blocked_policy`: перепиши промпт плана (`image_prompt`, действие) и
  попроси перегенерацию; не пытайся обходить модерацию.
