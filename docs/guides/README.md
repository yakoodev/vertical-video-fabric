# Гайды для ИИ-монтажёров

База знаний для агентов (Claude, Gemini и тех, кто будет вести каналы сам): как монтировать
вертикальные шортсы и горизонтальные ролики из стримов, сериалов и промо **нашими инструментами**.
Это ремесло; механика инструментов — в [`docs/AGENTS.md`](../AGENTS.md), контракт слоёв —
[`docs/motion/spec.md`](../motion/spec.md), паки — [`docs/motion/assets.md`](../motion/assets.md).
Где гайд и AGENTS.md расходятся — прав AGENTS.md и слова владельца.

## Как пользоваться

1. Перед монтажом — гайд по типу материала (`stream-clips.md` или `series-clips.md`) и `get_performance`.
2. Во время — `editing-rhythm.md` (структура), `subtitles.md`, затем слои: `motion-design.md`, `fx.md`,
   звук: `sound-design.md`.
3. Перед сдачей — шпаргалка ниже. Каждый пункт проверяется инструментом, а не памятью.
4. Правила канала (что разрешил/запретил владелец) важнее общих правил гайда. Не знаешь правила
   канала — спроси.

## Перед сдачей ролика проверь

**Линт** (`lint_clip` по свежему рендеру; в редакторе — «🔎 Проверка перед сдачей»)
- [ ] Нет `warn`: текст, субтитры, плашка и стикеры не под кнопками и подписью TikTok/Reels/Shorts (у Reels
      подпись выше), титры успевают прочитать (≥ 0.3 с/слово + 0.5 с), вспышек > 3 в секунду нет.
- [ ] Мему и Shorts под повторы — оценка `loop` и её подсказки (`set_end_hold(0)`, хвост без тишины).

**Структура** (`contact_sheet` n 12–16, `listen`)
- [ ] Первые 0.5 с — речь или действие, никакой заставки; хук (событие или титр) в первые 3 с.
- [ ] Каждые 2–4 с что-то новое: склейка, наезд, титр, смена плана.
- [ ] Нет пауз > 1 с без события (QC: `тишина`, `картинка стоит`).
- [ ] Конец на развязке + 0.5–1 с реакции; не на полуслове и не на новой теме.

**Кадр** (`view_frame` на хуке, 1–2 панчлайнах, финале)
- [ ] Текст по центру, в зоне: не выше 192 px и не ниже 1536 px (субтитры ≤ 1574), правее ≈ 940 px пусто
      (`lint_clip` `ui_zones` проверит по каждой площадке).
- [ ] Ничего на лице героя; плашки и картинки ≤ 40 % кадра; интерфейс игры не закрыт.
- [ ] Кегль ≥ 56 px (хук 96–120, панчлайн 130–170), контраст или обводка; 1 акцентный цвет.
- [ ] Графики одновременно ≤ 3 слоя; одно главное движение за раз; эмодзи нет.

**Субтитры**
- [ ] Есть; каждая фраза сверена со смыслом, имена и сленг правильные.
- [ ] 2–4 слова на странице; подсветка ≤ 1 слова на 2–3 с, не жёлтым.
- [ ] Мат: середина слова заглушена, в тексте звёздочки, `listen` слово не распознаёт.
- [ ] Второй голос — своим слоем, мельче и другим цветом.

**Звук** (`listen`)
- [ ] Голос разборчив и над игрой/музыкой; запись с двумя дорожками — `speech_tracks` на микрофон.
- [ ] Эффектов 0–2, каждый на слове/событии; никаких «дзынь/клик».
- [ ] Музыка без слов; на промо — с `energy_start_sec`.
- [ ] QC без `тихо`/`пережато`/`пик` (сервис сам доводит до −14 LUFS).

**Публикация** ([covers.md](covers.md))
- [ ] Обложка выбрана (`generate_covers` → `choose_cover`), титр не на лице, 2–5 слов, без эмодзи.
- [ ] Заголовок и описание (сервис пишет их после рендера) не нарушают правил канала и не врут.

**Отчёт** — 3–6 пунктов «что сделал, на какой секунде», и что осталось сомнительным.
