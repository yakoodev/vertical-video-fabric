# Моушн-дизайн: анимация слоёв, типографика, зоны, цвет

Как двигать титры, плашки, стикеры и камеру так, чтобы ролик выглядел дорого, а не «шаблонно».
Поля и типы слоёв — `docs/motion/spec.md`. Кадр — опорные 1080×1920, 30 кадр/с (1 кадр ≈ 33 мс).

## Принципы анимации — нашими средствами

| Принцип | Что значит | Как у нас |
|---|---|---|
| Замедление на входе/выходе | ничто не стартует и не встаёт мгновенно | `ease` у ключей; `linear` только для бесконечного движения (`loop spin`) |
| Перелёт (overshoot) и доводка | объект проскакивает цель и садится | `outBack`, `"bezier(0.3,1.6,0.6,1)"`, вход `pop` (0→1.1→1) |
| Подготовка (anticipation) | короткое движение «назад» перед главным | ключи `scale` 1 → 0.92 (0.08 с) → 1.15 → 1; райзер перед ударом |
| Сжатие-растяжение | масса и упругость | `pop`, `drop`; у PNGtuber `bounce` |
| Нахлёст и запаздывание | части едут не одновременно | вход `words`/`rise`, `stagger` слоёв по 2–3 кадра |
| Тайминг | скорость = вес и характер | быстро 0.15–0.25 с — лёгкое/дерзкое; 0.4–0.6 с — тяжёлое/«дорогое» |
| Дуги | живое движение идёт по дуге | `bend` у line/arrow; разные `ease` у ключей `x` и `y` (x `linear`, y `outQuad`) |
| Вторичное действие | мелкое движение поддерживает главное | `loop float`/`wiggle` с `amount` 0.2–0.4 у стикера |
| Преувеличение | акцент крупнее жизни | панчлайн 130–170 px, `wordScale` 1.15–1.3 |
| Постановка | один центр внимания | одна главная надпись на экране, всё остальное тише |

## Easing и длительности

- Вход — **ease-out** (`outCubic`, `outBack`, `outQuad`): быстро появился и мягко сел.
- Выход — **ease-in** (`inCubic`) и **короче входа** (≈ 60–70 %: вход 0.3 с → выход 0.2 с).
- Перемещение внутри кадра — `inOutCubic` (по умолчанию).
- `outElastic`, `outBounce` — только для комедии и мемов, не чаще раза на ролик.
- `step` — для жёстких «склеек» крупности и листания экранов.

| Элемент | Вход | Держать | Выход |
|---|---|---|---|
| Слово-панчлайн | `pop` 0.2–0.3 с | 0.8–1.5 с | `fade` 0.15–0.2 с |
| Хук | `words`/`pop` 0.3–0.4 с | 2–3 с | `fade` 0.2 с |
| Титр промо | `rise` 0.45–0.6 с | ≥ время чтения | `rise` назад 0.3 с |
| Плашка / callout | `slideUp`/`wipe` 0.3–0.4 с | 2–4 с | `fade` 0.2–0.25 с |
| Стикер, мем-картинка | `pop` 0.25 с | 1.5–2.5 с | `fade`/`zoom` 0.2 с |
| Стрелка, обводка | `draw` 0.3–0.5 с | пока нужно | `fade` 0.2 с |

`duration` входа/выхода не больше половины длины слоя (схема и так зажмёт). Слой до самого конца
ролика — выход не играет, он держится на стоп-кадре.

## Stagger и количество движения

- Слова — `words`/`rise`: сервис сам разносит слова. Несколько слоёв (список, иконки) — сдвиг `start`
  на 0.06–0.1 с (2–3 кадра) друг от друга, сверху вниз или слева направо — по порядку чтения.
- В каждый момент **одно главное движение**. Пока въезжает титр, мем не прыгает, а камера не наезжает.
- Графики одновременно ≤ 3 слоя (линт 9:16; фон, частицы и `behind` не считаются); 16:9 — ≤ 5.
- Постоянное движение (`loop`) — у одного слоя на экране и слабое (`amount` ≤ 0.5). Трясущийся текст
  дольше 1.5 с утомляет.
- Россыпь искр — один слой `particles`, не десятки `shape`.

## Кинетическая типографика

- Текст на экране — **из речи**, 2–5 слов. Ярлыки-категории («СМЕТА», «БРОНЬ») и заголовки
  с тире — нет (владелец: «человечнее»).
- Время чтения: ≥ 0.3 с на слово + 0.5 с, минимум 1 с на любую надпись.
- Шрифты: одно семейство на ролик (+ второе для акцента максимум). Мемы — `Oswald 700` или
  `Alumni Sans 900`; хуки и панчлайны — `Montserrat 900`, `Rubik 900`, `Unbounded 900`; промо — `Nunito`,
  `Unbounded`; разговорное — `Golos Text`, `Manrope`.
- Кегль 9:16: основной текст ≥ 56 px (линт пропускает от 44), хук 96–120, панчлайн 130–170, финальная
  ссылка ≥ 56. 16:9 — ≥ 36 (от 28).
- Ширина строки ≤ 900 px (`maxWidth`), не больше 2 строк у титра, 3 — предел.
- Капс — для коротких ударов (1–4 слова). Фраза из 6+ слов капсом читается хуже — пиши обычными.
- Акцентное слово в титре — `highlight` цветом или плашкой, не вторым шрифтом.

## Текстовые плашки

- Плашка `bg` нужна, когда фон пёстрый: `radius` 16–28, `padX` 24–36, `padY` 10–18, `opacity` 0.85–1.
  `skew` −8…−12° — для динамики (спорт, игры), не для серьёзного.
- Под титром на пёстром кадре без плашки — `backdrop: true` (мягкое затемнение 0.55).
- Обводка `stroke` 8–16 px чёрным — базовая читаемость белого/жёлтого текста на видео.
- Тень: `blur` 20–40, `y` 8–16, `opacity` 0.4–0.6 — объём без «грязи». Свечение — тень цветом акцента
  с `x = y = 0`, только на тёмном фоне.
- Непрозрачные плашки и картинки — ≤ 40 % кадра и не на лице (`add_layers` откажет).

## Безопасные зоны 9:16 (1080×1920)

| Зона | Доли кадра | px |
|---|---|---|
| Верх: шапка, ник, поиск | 0–0.10 | 0–192 — текста нет |
| Центр текста слоёв | y 0.15–0.72 | 288–1382 |
| Низ текста слоёв | ≤ 0.80 | ≤ 1536 |
| Низ субтитров | ≤ 0.82 | ≤ 1574 |
| Правая колонка кнопок (TikTok/Reels/Shorts) | x ≥ ≈ 0.87 в нижней половине | правее ≈ 940 px — ничего важного |

- Сервис проверяет верх/низ, но **не правый край** — держи ключевой текст по центру (`x = 0.5`).
- Reels закрывает низ сильнее (подпись поста бывает длинной): самое важное — выше 0.65 (≈ 1250 px).
- 1:1/4:5/16:9 — свои поля (AGENTS.md, «Безопасные зоны площадок»); у 16:9 — угол водяного знака.
- В `split` верх кадра — вебка: хук под полосой (`positions.hook`).

## Читаемость на телефоне и цвет

- Проверка — `view_frame` (кадр 540×960 близок к телефону): читаешь с первого взгляда — годится.
- Контраст текста к фону ≥ 4.5:1 (крупный и жирный — от 3:1); финал промо линт проверяет сам.
- Палитра ролика: белый + чёрная обводка + **один** акцент. Подсветки владельца: звучащее слово
  жёлтое `#FFD600`/`#FFE81F`, эмоция/мат `#FF3B30`, смысл `#22C55E`. Бренд — свои цвета (`apply_brand`).
- Насыщенный красный и синий на тёмном — тонкими линиями не читаются: только крупно и с обводкой.
- Фоны (`aurora`/`grid`/`bokeh`/`waves`) — `intensity` 0.5–0.8 под титрами; неон-сетка — игры и техно,
  аврора и боке — разговор. Сплошная заливка — только по просьбе.
- Лук клипа — пресет (`preset_id`: «Кинематограф», «Тёплый», «Сочный», «Нуар», «Плёнка»…). Один лук
  на ролик; «Плёнка (недоэдит)» и «Винтаж» — для стилизации, не по умолчанию.

## 3D-сцены (слой `scene`)

Движок сцен ([scene-engine.md](../motion/scene-engine.md)) — для интро, раскрытия, концовки, «вау»
на кульминации; не для каждого титра.

- **Стиль, а не реализм.** toon с 2–3 полосами + чернильная обводка (`outline` 4–6 px) читается на
  телефоне лучше «честного» света; `rim` отделяет объект от тёмного фона; `halftone`/`hatch` — комикс.
  Один стиль на сцену (`style`), акцент — цветом одного объекта.
- **Движение камеры — одно и медленное:** облёт 15–30°/с или плавный наезд; тряска — только на удар
  (`shake.amount` ключами 12 → 0 за 0.5 с). Ортокамера — для «чистого 2D»: инфографика, плашки,
  изометрия.
- **Вход пружиной:** `enter` со `spring {stiffness 170–260, damping 11–15}` — живой перелёт;
  каскад — `split: "letters"` + `stagger` 0.04–0.08 (буквы), `repeat` + `stagger` 0.1–0.15 (карточки).
- **Глубина работает на чтение:** титр ближе к камере и без тумана (`material.fog: false`), фон —
  дальше и в тумане; параллакс виден при разной `z` и движении камеры вбок.
- Проверяй `preview_scene_frame` на входе, в середине и на выходе: текст влез во вьюпорт, объект не
  обрезан краем, пол не перекрыл объекты (`order: -1`).

## Делай / не делай

| Делай | Не делай |
|---|---|
| Одно главное движение за раз | Всё влетает одновременно |
| Выход быстрее входа | Одинаковый `fade` 0.5 с на всё |
| Текст по центру, из речи | Текст «в пустое место» сбоку, канцелярит |
| 1 акцентный цвет | Радуга из 4–5 цветов |
| Тайминг по слову (`at_word`) | Титр на секунду раньше/позже слова |
| `view_frame` на пике каждой анимации | Сдавать по JSON, не глядя |
