# Клипы со стримов: Twitch, VTuber, игры

Стрим — часы материала, в которых 1–3 % годится в шортс. Задача — найти момент, рассказать его
за 15–60 с и сохранить ощущение «это было в эфире».

## Где искать моменты

| Сигнал | Инструмент | Заметка |
|---|---|---|
| Всплеск чата (KEKW, «ахаха», «+», «F») | `chat_activity`, `get_chat` | событие на 5–20 с **раньше** всплеска |
| Громкость: крик, смех, взрывы | `source_loudness` (окна ≤ 10 мин) | пики над медианой + 6 дБ; 4-часовой VOD — окнами подряд |
| Речь: история, шутка, спор | `get_source_transcript` | ищи завязку и развязку в репликах |
| Картинка | `source_contact_sheet` | смешное не только в звуке? |
| Что уже зашло | `get_performance` | повторяй типы моментов из топа |

Хороший момент самодостаточен: понятен без остального стрима. Типы, которые заходят: фейл и реакция,
неожиданный поворот, вспышка эмоции, удачная шутка, «эпик» в игре, разговор с чатом/донатом,
коллаб-перепалка.

Не брать: лобби, меню, загрузки, стрельбище, «ждём катку», монотонная болтовня, момент «понятно
только тем, кто смотрел час», чужие ролики/песни с текстом на экране, окна рабочего стола и
уведомления (приватность — подрезай, не прикрывай плашкой).

## Структура клипа

1. **Контекст 3–10 с** — ровно столько, сколько нужно, чтобы понять развязку. Не 30 с предыстории.
2. **Нарастание** — без мёртвых пауз (`suggest_cuts`), но не режь дыхание сцены.
3. **Развязка** — панчлайн, фейл, килл, крик.
4. **Реакция 0.5–1.5 с** — лицо/голос стримера после события. Без реакции стрим-клип теряет половину.

- Файт в игре — **целиком**: от первого контакта до вайпа/смерти/победы, с запасом 3–5 с до первого
  выстрела и после последнего килла + реакция. Середину файта не вырезать. Длина — сколько идёт файт
  (хоть 2–3 мин).
- Вырезка самого стримера (DVR-клип, его отметка) — держи почти целиком, режь только мёртвые края.
- Одна запись — один клип, если владелец не просил больше.

## Подача

- **Раскладка:** вебка полосой + игра (`split`, `cam_pos: top`, `ratio` под пропорции вебки), вебка
  окошком (`pip_cam`), PNGtuber крупно поверх игры (`add_pngtuber`, голос — дорожка микрофона 1).
  Чат-разговор без игры — `single` на лице. История витубера «только аватар» поверх браузера/игры —
  `detect_avatar` → `set_layout avatar_full` (плейбук `vtuber-story`): окно 9:16 по исходнику ловит
  ролик или игру на экране, а не модель.
- **Звук:** запись NVIDIA/OBS — две дорожки. `set_source_audio(tracks: [0, {track: 1, gain_db: "auto"}],
  speech_tracks: [1])` — голос над игрой, субтитры по микрофону. Пустой/шумный микрофон — скажи владельцу.
- **Субтитры** — всегда, по микрофону; каждую фразу сверить (`subtitles.md`). Мат — глушить середину
  слова + звёздочки.
- **Титры** — человеческие, на сленге аудитории, 1–2 на ролик («заруинил катку», «переобулся посреди
  файта»). Не канцелярит и не пересказ.
- **Хук-титр** — зависит от канала: у Apex-канала владельца **без текста в начале** (событие и есть
  хук); у других — по `positions.hook`. Не знаешь правило канала — спроси.
- **Мемы** — в точку на панчлайне, ≤ 2 на ролик, не на лице. Реальные люди на мем-фото, чужие
  мультфильмы и песни — не брать.
- **Звуки** — 0–2, на панчлайне. Игра и так шумная: эффект только там, где игра стихла.
- **Чат на экране** (`chat`, шаблон «Чат стрима») — когда реакция чата сама часть шутки.
- **Плашка канала** — по правилу владельца (например, Mura: тёмная «стеклянная» плашка, значок Twitch +
  ник слева, ниже стыка вебки/игры, мимо субтитров).

## VTuber

- Аватар на зелёнке — хромакей источника, фон `set_backdrop` (анимированный, в цветах модели); слои за
  персонажем — `behind: true`. На неподвижном персонаже вырезы видны как рывок головы: короткие паузы
  не режь, длинные — с наездом камеры на стыке.
- Модель — лицо канала: не закрывать её титрами и мемами; крупность — `meme`, `video_scale` 2–3;
  модель поверх экрана (браузер, ютуб, игра) — `avatar_full`: только её прямоугольник на весь кадр.
- Голоса коллабов и TTS-донаты — отдельный слой субтитров (B/C/D, мельче, другим цветом).
- Правила агентств (Hololive/Cover и др.) для клипперов: не перезаливать стрим целиком, указывать
  ссылку на оригинал, не брать запрещённые к клипам части (мембершип, караоке с чужой музыкой).
  Если клипы чужого VTuber — сначала его правила, потом монтаж.
- Ник и лор: имена персонажей, мемы фандома — подписывай правильно; не знаешь — не выдумывай.

## Горизонталь со стрима (16:9)

- Это «лучшее за стрим»: 3–10 моментов подряд (`make_compilation` или `create_clip` по кускам), 3–10 мин.
- Между моментами — `fadeblack` 0.3–0.4 с или короткая плашка-заголовок момента; внутри момента — встык.
- Субтитры уже, строка ≤ 64 % ширины (сервис сам), вебка окошком в углу.

## Делай / не делай

| Делай | Не делай |
|---|---|
| Событие + реакция стримера | Обрезать реакцию ради длины |
| Файт целиком с запасом по краям | Вырезать середину файта |
| Голос над игрой, субтитры по микрофону | Субтитры по смеси игры и голоса |
| 1–2 живые подписи на сленге | Канцелярские плашки и пересказ |
| Спросить правило канала | Переносить правила одного канала на другой |
