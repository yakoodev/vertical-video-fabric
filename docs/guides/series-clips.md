# Клипы из сериалов, мультфильмов и аниме

Зритель шортса не смотрел серию: он не знает героев, их отношений и того, что было 5 минут назад.
Клип должен работать **с нуля**. Второе ограничение — права: голая перезаливка сцены — не монтаж.

## Отбор моментов

- Режим анализа выбирается текстом промпта: **аниме — хайлайты** (3–5 самостоятельных моментов),
  **сериал — пересказ** (Episode Story Recap первым клипом + моменты). Не смешивай.
- Годится: законченная шутка, перепалка с панчлайном, поворот, эмоциональный пик, «цитата», сцена-
  реакция. Длина 20–60 с.
- Не годится: сцена, смысл которой в прошлых сериях; длинный разговор без развязки; кульминация
  сезона, которую стыдно спойлерить без предупреждения.
- Режь по фразе: начало — с первой реплики сцены (или за 0.3–0.5 с до неё), конец — после реакции на
  последнюю реплику, не на полуслове (`get_clip`/`trim_piece` предупредят).
- Песня с текстом в сцене (опенинг, вставка) — отдельный риск по правам; лучше не брать.

## Контекст за 3 секунды

- Хук-титр объясняет ситуацию, а не называет серию: «ОН ПЕРЕПУТАЛ ЕЁ С МАМОЙ», а не «Сезон 2, серия 5».
- Имя героя — в титре один раз, если без него непонятно; дальше субтитры.
- Нужна предыстория — 1 строка титра в начале или стоп-кадр 0.5–1 с с подписью (`freeze_frame`), а не
  лишние 20 с прошлой сцены.

## Кадр 9:16 из 16:9

Окно видит ≈ треть ширины (`framing.window_w` ≈ 0.32), а планы меняются каждые 2–5 с.

1. **Сначала субтитры** (и `separate_voices`, если голосов несколько) — без них `auto_focus` не знает,
   кто говорит в длинном плане.
2. `auto_focus(clip_id)` — говорящий на каждом плане, жёсткая смена на склейках, плавный поворот к
   ответившему в длинном плане.
3. Проверь `contact_sheet`; промах (стена, дверь, не тот герой) — `set_focus` этого куска по `get_shots`.
4. Двое по краям широкого плана — по приоритету: фокус на говорящем с `cut: true` на его реплике →
   поворот 0.3–0.5 с → кусок «шире окна» `set_piece_fit(w ≈ 0.6, bg: blur)` только на этот план
   (≤ 12 с, вынеси его отдельным куском).

## Монтаж диалога

- Смена плана — на реплике или реакции. Панчлайн часто сильнее на **лице слушающего**: держи его
  реакцию 0.5–1 с.
- Склейки исходника уже есть — не добавляй переходы внутри сцены. Между разными сценами — `cut` или
  `fadeblack` 0.3 с («позже»).
- Пауза перед ответом — часть шутки: `apply_cuts` на ней не применяй.
- Наезд камеры — на реакцию или ключевую фразу, 1.0 → 1.15–1.25; в мультфильмах с плоским кадром
  наезд заметнее — мягче.
- Мемы и стикеры поверх сериала — редко: лицо говорящего обычно в центре окна. Только если `view_frame`
  показывает пустое место.

## Аниме

- Самостоятельные моменты, не пересказ серии. Хорошо работают: гэг с реакцией, «эпичное» появление,
  сцена-цитата, шок-поворот.
- Аниме-реплики короткие и с паузами — субтитры страницами по 2–3 слова, имена — как в принятом
  переводе (Наруто, не «Наруто-кун», если не важно).
- Цветной стиль сохраняй: лук «Чистый» или «Сочный»; «Нуар»/«Плёнка» ломают стиль студии.
- Для эдита под музыку (AMV-стиль) — отдельный формат: склейки на долях, `zoompunch`/`flash` на дропе.
  Музыку берёт только владелец (права на трек — отдельно от прав на аниме).

## Права и трансформация

Сервис не юрист; ориентиры практиков:

- Голая сцена с субтитрами — не трансформация. Добавляй смысл: подачу (хук, пересказ контекста),
  монтаж (сборка из нескольких сцен, реакции), комментарий.
- Не делай клип, который заменяет просмотр серии (полный пересказ каждого поворота).
- Японское право не знает «fair use»: даже секунды узнаваемого материала могут дать претензию.
- Владелец решает, какие тайтлы можно резать; сомневаешься — спроси до монтажа.

## Делай / не делай

| Делай | Не делай |
|---|---|
| Хук объясняет ситуацию за 3 с | Хук «Серия 5, сезон 2» |
| Сначала субтитры, потом `auto_focus` | Подбирать `x` на глаз с нуля |
| Реакция слушающего на панчлайне | Резать сразу после фразы |
| `set_piece_fit` на короткий двухплан | Весь клип мелким видео на размытом фоне |
| Конец на реакции | Конец на первой фразе новой сцены |
