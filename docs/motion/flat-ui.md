# Плоская тема (`flat theme`) и слой `ui`

Плоская графика ролика — плашки, карточки с числами, чек-листы, окна браузера и чата, уведомления, хук-слово —
собирается из **одной системы токенов**. Ориентир — реф «ошибки новичка»
(`D:\vvf-offload\refs\flat_graphics\ref_3_errors.mp4`): одна связная палитра, тёмные скруглённые карточки с тонкой
кромкой и воздухом внутри, подписи капсом в разрядку, пилюли-чипы, крупные жирные цифры, полосы прогресса,
размытый и притушенный фон под плашками, общая тень, огромное слово на кадре 0, чистые значки вместо эмодзи.

Одна правда для трёх мест:

| где | что рисует |
|---|---|
| 2D-слой `ui` моушна (превью редактора и компоновщик) | `frontend/src/motion/layers/flatui.ts` → компоненты `flat/` |
| шаблоны галереи «Плоский UI» (редактор, `list_motion_templates` / `add_motion_template` агента) | `frontend/src/motion/templates/flat.ts` |
| плоские экраны в 3D (монитор с браузером/чатом, уведомления телефона, ярлык, HUD, всплывающая карточка) | `node/scene3d/src/ui_flat.ts` → те же компоненты |

## Токены (`frontend/src/motion/flat/tokens.ts`)

**Темы** (`theme`):

| тема | основа / карточка | акцент | для чего |
|---|---|---|---|
| `red` | почти чёрный с тёплым отливом `#0c0607` / `#141012` | `#ff2d46`, со свечением | как реф: «ошибки», хайп, TikTok-объяснялки |
| `dark` | графит `#0a0b10` / `#15171e` | индиго `#6c5cff` | нейтрально, сервис/продукт (как рекламный пакет) |
| `light` | `#f3f4f7` / белые карточки | синий `#2f6bff` | светлые сцены, экраны в 3D, «чистый» интерфейс |
| `brand` | `plate` бренда (тёмная → тёмная тема, светлая → светлая), поверхности подкрашены акцентом | `accent` бренда | под проект; текст на акценте — читаемый (белый/почти чёрный по контрасту) |

`accent` перекрашивает акцент любой темы. В `add_motion_template` тема `brand` без своих `accent`/`plate` берёт
цвета бренда проекта клипа (`brands.colors.accent/plate`). У темы — поверхности `surface/surface2/surface3`,
кромка `border`, текст `text/muted/faint`, `accent/accentText/accentSoft`, `success/warning/danger`, `shadow`,
`scrim`; контраст основного текста на карточке ≥ 7:1 (проверяет тест).

**Геометрия и типографика** (опорные px кадра 1080×1920): скругления `RADII` xs 10 · sm 16 · md 24 · lg 34 · xl 46 ·
pill; отступы `SPACE` по сетке 4 (поле карточки 44); кромка 2 px (сверху светлее — «стекло»); тени `SHADOWS` card
(blur 56, y 22, 0.5) · float · chip · glow (свечение акцентом). Шрифты — из `vendor/fonts`: **display** Montserrat 900
(хук, заголовки, чипы, цифры), **body** Golos Text 500/700/900 (подписи, пункты, тексты). Шкала `TYPE`: hook 200 ·
number 120 · title 76 · heading 44 · chip 36 · body/item 36 · sub 27 · label 25 (капс, разрядка 0.14 em) · caption 25.

## Значки — Lucide

`frontend/src/motion/flat/icons.ts` — подмножество **Lucide** (https://lucide.dev, `lucide-static` 0.460.0),
**лицензия ISC** (части из Feather — MIT), текст — `frontend/src/motion/flat/LUCIDE_LICENSE.txt`. 115 значков
(галочки, предупреждения, глаз, сердце, часы, песочные часы, рост/падение, графики, деньги, замок, щит, ракета,
кубок, видео, микрофон, окна, бот, искры…), чужих логотипов нет. Имена — как на lucide.dev (`eye`, `hourglass`,
`circle-check`, `trending-up`, `message-circle`…) или русские алиасы (`глаз`, `галочка`, `часы`, `рост`, `деньги`).
Пути рисуются своим разбором SVG (дуги — центром, `ctx.ellipse`), без `Path2D` — одинаково в браузере, в
@napi-rs/canvas и в 3D. Новый значок: строки путей элементов из `icon-nodes.json` пакета → в `FLAT_ICONS`.

## Слой `ui`

`props.component` и общие поля (всё, кроме `component`, необязательно — умолчания знает движок):

| поле | смысл |
|---|---|
| `theme`, `accent`, `plate` | тема и цвета (см. выше) |
| `variant` | chip `solid`/`soft`/`outline`/`neutral`; title `plain`/`card`; hook `plain`/`fill`/`accent`; counter `pill`/`accent`/`plain`; checklist `card`/`window`; window `app`/`browser`/`chat`; toast `light`/`dark` (нет — по теме) |
| `w`, `h`, `size` | ширина, высота окна, кегль главного текста |
| `label` | подпись капсом (stat, bars, checklist), чип над заголовком (title), имя приложения (window, checklist window) |
| `title`, `text`, `icon` | главный текст, второй текст, значок Lucide |
| `value`, `from`, `decimals`, `prefix`, `suffix`, `unit`, `delta` | число: растёт от `from` к `value` по ходу `progress` слоя (нет ключей — за ≤ 1.6 с после входа); `unit` — слово после числа; `delta` — чип изменения («+340%», «−41%» — стрелка вниз) |
| `progress` | полоса в карточке с числом, 0..1 |
| `items` | `[{text, sub, note, icon, value, max, color, dim, at, done, from}]` ≤ 10 — пункты чек-листа, полосы сравнения, сообщения окна-чата |
| `marker`, `markerLabel` | порог на полосах (доля 0..1) с подписью («1:00») |
| `url`, `time`, `badge`, `letter` | адрес браузера; время, счётчик и буква значка уведомления |
| `delay`, `stagger`, `reveal` | время пунктов: первый на `delay` с слоя (0.5), дальше через `stagger` (0.6); `item.at` — своя секунда; checklist `check` — все видны, галочки по одной; `appear` — пункты появляются по одному |
| `font`, `bodyFont` | свои гарнитуры display / body |

Компоненты:

- **hook** — огромное слово во всю ширину (`w` 1000, кегль подгоняется), `\n` — строки, `text` — подпись.
  `variant: fill` — своя заставка темы во весь кадр (основа + свечение акцентом); такой слой ≤ 3 с — «короткая
  вставка» для правила «не закрывать видео». Ставится **без `in`**: хук читается на кадре 0.
- **chip** — пилюля капсом со свечением акцента («ОШИБКА 1», «3 СЕКУНДЫ»), значок слева.
- **title** — чип `label` + крупный `title` + `text`; `plain` — с тенью поверх кадра, `card` — на карточке.
- **stat** — подпись капсом со значком, крупное число с `unit`, чип `delta`, полоса `progress`, пояснение `text`.
- **bars** — сравнение: строки `text` + `note` справа, полосы `value/max` растут по очереди, `dim` — бледная
  («было»), метка-порог `marker`.
- **counter** — пилюля: кружок со значком, число растёт, `unit` («942 692 просмотров»).
- **checklist** — `title` и пункты с кружками-галочками; `done: false` — пункт так и остаётся бледным;
  `variant: window` — в окне с точками и именем приложения `label`.
- **toast** — уведомление телефона: значок приложения (Lucide или буква), имя `title`, время, `text` до двух
  строк, `badge`.
- **window** — окно с «светофором»: `app` (имя в шапке, `title` — заголовок в теле, `text` или `items` чек-листом),
  `browser` (адресная строка с замком `url`), `chat` (`items` пузырями: `from: me` — справа акцентом, `them` —
  слева; перед ответом — «печатает…»).

Рамка слоя для перекомпоновки и линтов — оценка `ui_size` (app/aspect.py) ↔ `uiSize` (reframe.ts), сверка —
фикстура `tests/fixtures/reframe_cases.json`.

## Фон под плашками — `fx` `backdrop`

Эффект кадра: всё ниже по дорожкам размыто (`size` — радиус, опорн. px, 22; до 64) и притушено (`intensity` 0.45,
`color` — оттенок затемнения, по умолчанию почти чёрный; светлый — «матовое стекло» для светлой темы) с лёгкой
виньеткой. Вход/выход — `fade` слоя (резкий кадр плавно уходит в размытый). Субтитры (`captions`) и плашка канала
ниже по дорожкам **поднимаются над ним** — остаются резкими. Ставится одним слоем на всё время плашек на дорожку
ниже карточек (шаблоны: дорожка 4 — фон, 5 — карточка). Размытие — на копии в 1/4 кадра: дёшево и без ореола у краёв.

## Шаблоны «Плоский UI»

`list_motion_templates(category: "Плоский UI")` → `add_motion_template(template, params, at)`; у всех — `theme`
(`red`/`dark`/`light`/`brand`), `accent`, `plate`, у карточек — `backdrop` (фон под плашкой).

| id | что |
|---|---|
| `flat-hook` | хук-слово во весь кадр (`word`, `sub`, `fill`, `accentLast`) — первый кадр ролика |
| `flat-error` | чип + заголовок («Ошибка 1» / «Скучное начало», `sub`, `card`) |
| `flat-stat` | карточка с числом (`label`, `icon`, `value`, `from`, `prefix`, `suffix`, `unit`, `delta`, `progress` %, `caption`) |
| `flat-compare` | сравнение полосами (`rows` «текст \| значение \| заметка; …», `max`, `marker`, `markerLabel`, `dimFirst`) |
| `flat-checklist` | чек-лист в окне (`app`, `title`, `items` «текст \| подпись; …», `undone`, `stagger`, `appear`) |
| `flat-toast` | уведомление (`app`, `text`, `time`, `icon`, `badge`, `glass`) |
| `flat-window` | окно браузера / чата / приложения (`kind`, `app`, `url`, `title`, `text`, `messages` «me: …; them: …») |
| `flat-counter` | счётчик-пилюля (`value`, `from`, `unit`, `icon`, `style`) |
| `flat-chip` | чип / бейдж (`text`, `icon`, `style`, `size`, `tilt`) |
| `flat-backdrop` | фон под плашками (`blur`, `dim`) |

Старые шаблоны `counter`, `progress`, `top-3`, `lower-third-*` получили параметр `theme`: `classic` (по умолчанию)
— прежний вид и прежние слои, `red`/`dark`/`light`/`brand` — слой `ui` в плоской теме. Параметры прежние.

Рецепт ролика в стиле рефа: `flat-hook` (0–1.1 с, `fill`) → `flat-backdrop` на всё время плашек → по разделу
`flat-error` сверху + карточка (`flat-stat` / `flat-compare`) в середине → `flat-checklist` → `flat-toast` /
`flat-counter` в конце; одна тема на ролик.

## 3D-экраны (`node/scene3d`)

Поле `theme` у спецификаций: монитор (`browser.theme`, страница `page.theme`, у вкладки — `url` адресной строки),
`panelParams.theme` у картинок облачков (счётчик просмотров, адресная строка запуска), телефон-уведомления
(`theme` экрана), оверлеи `hud` / `tag` / `toast` (`theme`, `accent`). Не задано — плоская тема (монитор и
уведомления — `light`, HUD и ярлык — `dark`, счётчик — `red`); `"toon"` — прежний мультяшный вид для рисованных
сцен. Шрифты Montserrat и Golos Text грузятся под своими именами (`loadUiFonts`).
