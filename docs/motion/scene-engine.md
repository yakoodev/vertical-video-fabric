# Движок сцен: слой `scene` (кодовая 3D/2D-анимация)

Свой движок анимации «кодом»: JSON-сцена → кадр, одним слоем `scene` в обычном компоновщике.
Настоящее 3D (сетки, перспектива, облёт камеры, свет) и чистое 2D (ортокамера с наездами и
панорамами) в одном формате, стилизованные заливки (toon/cel, градиент, halftone, штрих, обводка).
Пишут сцены ИИ-агенты (Gemini/Claude по MCP) и человек в инспекторе.

- Код: `frontend/src/motion/scene/` (`render.ts` — конвейер, `traverse.ts` — обход узлов и текст,
  `drawMesh.ts` и `drawMedia.ts` — рисование, `shade.ts` и `lighting.ts` — цвет и свет, `geometry.ts` — сетки и контуры,
  `value.ts` — анимации, `expr.ts` — выражения, `validate.ts` — проверка, `templates.ts` — шаблоны),
  слой — `frontend/src/motion/layers/scene.ts`, сервис — `app/scene_engine.py`.
- **Превью = рендер**: тот же TypeScript рисует в браузере (Canvas 2D) и в Node (`@napi-rs/canvas`,
  Skia) — без WebGL. Тест `CLI: слой scene в кадре компоновщика = кадр движка` сверяет пиксели.
- **Кадр = f(t)**: ни `Date`, ни `Math.random`; случайность только сидовая. Перемотка в любую точку
  даёт тот же кадр (тест «тот же t — те же пиксели»).

## Слой

```json
{ "id": "s1", "type": "scene", "start": 2, "end": 6, "x": 0.5, "y": 0.4,
  "props": { "w": 1080, "h": 1100, "clip": true, "scene": { "nodes": [ … ] } } }
```

| поле | что |
|---|---|
| `w`, `h` | вьюпорт сцены в опорных px; нет — весь опорный кадр формата (1080×1920 у 9:16). Центр вьюпорта — `x`/`y` слоя |
| `clip` | обрезать рисунок по вьюпорту (по умолчанию да) |
| `scene` | JSON-сцена (ниже). Сервис хранит только JSON: числа конечные, ≤ 200 000 символов, вложенность ≤ 40 |

Слой ведёт себя как любой другой: `scale`/`rotation`/`opacity` и их ключи, `in`/`out`, `loop`,
`followCamera`, `z`/`rotX`/`rotY` и 3D-камера клипа поверх (сцена — плоскость в кадре клипа).
Полупрозрачный слой гасится целиком через промежуточный холст (грани не просвечивают).
Время сцены `t` — секунды от `start` слоя. Правило «не закрывать видео» считает только сцену
с непрозрачным `background` (прозрачная — графика поверх).

## Единицы и оси

- Оси как в three.js: **x вправо, y вверх, z на зрителя**. Повороты — градусы, порядок X → Y → Z
  (внешние оси: M = Rz·Ry·Rx).
- **1 единица = 1 опорный px на плоскости z = 0 у камеры по умолчанию.** Камера по умолчанию —
  перспектива, `fov` 40°, стоит в `[0, 0, D]`, смотрит в начало координат, где
  `D = h/2 / tan(fov/2)` (≈ 2638 при h = 1920, ≈ 1236 при h = 900). Ставишь `position` сам —
  бери z ≈ D (в выражениях есть переменная `D`), иначе всё станет мельче или крупнее;
  проще `orbit` без `distance`.
- Ортокамера: `zoom` = px на единицу (1 — один в один), глубина влияет только на порядок и туман.

## Сцена

```json
{
  "camera": { "type": "perspective", "orbit": { "azimuth": 20, "elevation": 15 } },
  "lights": [ { "type": "ambient", "intensity": 0.4 }, { "type": "directional", "direction": [-1, 1, 1] } ],
  "fog": { "color": "#101018", "near": 2500, "far": 7000, "max": 0.8 },
  "background": { "gradient": ["#1b1035", "#3a1c71"], "angle": 90 },
  "style": { "shading": "toon", "bands": 3, "outline": { "color": "#140c2a", "width": 5 } },
  "seed": 7,
  "nodes": [ … ]
}
```

- `camera`: `type` perspective | orthographic; `position`, `target` (`[0,0,0]`), `up`; `fov` (40);
  `zoom` (1); `roll` (крен, °); `orbit {azimuth, elevation, distance, target}` вместо `position`
  (облёт вокруг цели: azimuth 0 — спереди, 90 — справа); `shake {amount (px), freq (Гц, 6), roll}`;
  `near` (5), `far`. Все числа анимируются.
- `lights` (нет — окружающий 0.42 + направленный сверху-слева-спереди): `ambient {color, intensity}`,
  `directional {direction — откуда светит, color, intensity}`, `point {position, range, …}`,
  `hemisphere {sky, ground, intensity}` (небо/земля — мягкий стилизованный свет).
- `fog {color, near, far, max}` — цвет уходит в туман по глубине (линейно near → far, до `max`).
- `background` — `"#hex"`, `{gradient: [c1, c2…], angle, radial}` (angle 90 — первый цвет снизу) или
  нет/`null` — прозрачно поверх видео. Фон экранный, камера его не двигает.
- `style` — материал по умолчанию для **сеток**. Текст и плоские фигуры без своего
  `material.shading` — без света, своим цветом (титр не темнеет от toon).
- `seed` — зерно сцены (вместе с id слоя: у копии слоя своя раскладка частиц/шума).

## Узлы

Общие поля любого узла:

| поле | что |
|---|---|
| `type` | тип (ниже); синонимы three.js/SVG понимаются: cube→box, ball→sphere, donut→torus, label→text… |
| `position`, `rotation`, `scale` | перенос, поворот (°), масштаб (число или `[x,y,z]`); всё анимируется |
| `pivot` | точка вращения в своих координатах (переворот карточки за край, качание колокольчика) |
| `opacity`, `color` | прозрачность (умножается вниз по дереву); `color` = `material.color` |
| `material` | материал (ниже); сливается с материалом родителя и `style` |
| `children` | дочерние узлы (у любого типа) |
| `start`, `end` | окно видимости в секундах узла |
| `delay`, `time {offset, speed, loop}` | время узла: сдвиг, скорость, петля |
| `stagger`, `staggerFrom` | сдвиг времени детей: i-й ребёнок на `i·stagger` позже; start/end/center/edges/random |
| `enter {from: {position, rotation, scale, opacity}, at, duration, ease \| spring}` | вход из позы к покою |
| `exit {to: {…}, at, duration, ease}` | выход; нет `at` — так, чтобы закончить к концу слоя |
| `follow {points, progress, closed, smooth, orient}` | полёт по сплайну Катмулла — Рома (progress 0..1; нет — за длину слоя) |
| `order` | целое: меньше — рисуется раньше (сильнее глубины) |
| `sort: "object"` | поддерево сортируется целиком по своему центру (внутри — по граням) |

### Сетки (3D)

| type | поля |
|---|---|
| `box` | `size` (число или `[w, h, d]`, 200) |
| `sphere` | `radius` (120), `segments` (32), `rings` (≈ 2/3 segments) — гладкий свет по умолчанию |
| `icosphere` | `radius`, `detail` 0..4 — гранёный low-poly |
| `cylinder` | `radius` или `radiusTop`/`radiusBottom`, `height`, `segments` (24), `caps` |
| `cone` | `radius`, `height`, `segments` (4 — пирамида, 6 — ёлка) |
| `plane` | `size [w, h]`, `segments` — в плоскости XY лицом к камере; пол — `rotation: [-90, 0, 0]` |
| `torus` | `radius` (кольцо), `tube` (толщина), `segments`, `tubeSegments` — в плоскости XY |
| `lathe` | `points [[радиус, y], …]` снизу вверх, `segments` — тело вращения (ваза, колокольчик) |
| `extrude` | контур: `shape` star/heart/circle/ellipse/polygon/rect/roundrect/arrow (`radius`, `size`, `spikes`, `inner`, `sides`, `cornerRadius`) или `points [[x,y]…]` или `d` (SVG-путь M L H V C S Q T Z; y SVG вниз — переворачивается; дуги A — нет; дырки не выдавливаются); `depth` |

### Плоские (2D в той же сцене)

`rect {size, cornerRadius}`, `circle {radius | size}`, `polygon {points | sides + radius}`,
`star {spikes, inner, radius}`, `path {d, closed}`, `shape {shape: …}`. Заливка `fill`
(`"#hex"`, `{gradient: [...], angle}`, `null`), обводка `stroke {color, width}`. Двусторонние;
проецируются честно (перспектива без приближений). Многоконтурный путь — `evenodd` (дырки есть).

### Текст

`text` (плоский) и `text3d` (выдавленный, `depth` 40): `text`, `size` (120), `font`, `weight` (900),
`italic`, `uppercase`, `align`, `lineHeight`, `letterSpacing`, `color`, `sideColor` (бока
выдавливания), `stroke`, `slices` (срезов выдавливания, ≤ 14), `material.outline` — чернильный
контур всего тела. **`split: "letters" | "words" | "lines"`** — каждая буква/слово отдельным узлом:
`enter`/`exit` играет каждая со сдвигом `stagger` (0.05), `letters {position, rotation, scale,
opacity}` — поза каждой буквы, в выражениях `i` — номер буквы. Текст односторонний (сзади не виден).

### Прочее

- `image {src | asset_id, width | size}` — файл из библиотеки, `emoji:1f525`, `sticker:…`; под
  перспективой картинка делится на треугольники (без «плавания» текстуры).
- `line {points [[x,y,z]…], width, color, progress (рисование 0..1), dash, closed, smooth}`.
- `repeat {count ≤ 500, child, layout line|grid|circle|random, spacing, cols, radius, axis y|z|x,
  arc, startAngle, face out|none, area, seed, colors (цвет копии i), stagger, step {position,
  rotation, scale} (накапливается ×i), jitter {position, rotation, scale} (сидовый разброс)}` —
  в выражениях копии `i`, `n`, `u = i/(n−1)`.
- `particles {kind confetti|snow|float|burst, count ≤ 600, area [w,h,d], size, colors, speed,
  spin, gravity, life, at, shape quad|dot, seed}` — настоящие 3D-листики (переворачиваются и
  блестят) или точки; `burst` — разлёт в момент `at`.

## Материал и стилизация

```json
"material": { "color": "#FF2D55", "shading": "toon", "bands": 3, "outline": { "width": 5 },
              "rim": { "color": "#ffffff", "strength": 0.6 }, "specular": { "size": 0.04 } }
```

| shading | вид |
|---|---|
| `flat` | цвет как есть (без света) |
| `lambert` | рассеянный свет; с `smooth: false` — гранёный low-poly |
| `toon` (по умолчанию у сеток) | 2..6 полос (`bands`); шкала `colors [тень…свет]` или `shadowColor` |
| `gradient` | плавная шкала `colors` по освещённости (градиентное «аниме»-затенение) |
| `halftone` | светлая заливка + растр точек в тени (`halftone {size, color}`), точки крупнее — темнее |
| `hatch` | штриховка тени, в глубокой тени — перекрёстная (`hatch {size, color}`) |

- **Гладкий свет** (`smooth`; у sphere/torus/cylinder/cone/lathe по умолчанию): нормали в вершинах
  сглажены (рёбра острее 60° остаются жёсткими). У полосатых заливок грань режется по порогам
  света — граница полосы ровная, как у cel-шейдера, а не ступеньками граней; у мягких —
  линейный градиент по грани (≈ Гуро).
- `outline {color, width, crease}` — чернильный контур: силуэт (ребро между лицевой и тыльной
  гранью), края и изломы острее `crease` (40°). Ширина — в px слоя, от глубины не зависит.
- `rim {color, strength, power}` — контровой свет по краю; у полосатых — жёсткой полосой.
- `specular {color, size}` — блик (у toon на гладком — жёсткое пятно).
- `emissive` — свечение (добавляется к цвету), `opacity`, `doubleSided`, `fog: false` — не тонуть
  в тумане, `seams: false` — без штриха против швов сглаживания.

## Анимация

Любое число и каждая компонента вектора/цвета:

| форма | пример |
|---|---|
| число | `30` |
| выражение | `"=200*sin(t*2) + i*40"` или `{ "expr": "…" }` |
| ключи | `{ "keys": [[0, 0], [1.2, 360, "outBack"]], "loop": 2 }` — ease точки действует до следующей; `loop` — период или `"pingpong"`; `v` вектора — массив |
| переход | `{ "from": 0, "to": 1, "at": 0.2, "duration": 0.6, "ease": "outBack" }` |
| пружина | `{ "from": 0, "to": 1, "at": 0.2, "spring": { "stiffness": 170, "damping": 14 } }` — аналитическая затухающая пружина, может перелететь |
| добавки | `{ "base": 100, "rate": 45, "wiggle": { "amp": 20, "freq": 1.5, "seed": 3 }, "osc": { "amp": 10, "freq": 0.5 } }` — складываются с основой (`keys`/`from`/`expr`/`base`) |
| цвет | `"#hex"` или `{ "keys": [[0, "#ff0000"], [1, "#0000ff"]] }` |

Кривые — те же, что у слоёв (linear, inQuad … outBounce, step, `bezier(x1,y1,x2,y2)`).
`wiggle` — сидовый шум (2 октавы), у каждой копии repeat и компоненты свой.

### Выражения

Свой разборщик (не `eval`): числа, `+ - * / % ^`, сравнения, `&& || !`, `?:`, функции `sin cos
tan asin acos atan atan2 abs sign floor ceil round fract sqrt exp log pow min max mod clamp lerp
mix step smoothstep pingpong tri deg rad`, сидовые `rand(k[, s])` ∈ [0,1) и `noise(x[, s])` ∈ [−1,1];
переменные `t` (время узла), `T` (слоя), `dur`, `p` (= T/dur), `i`, `n`, `u`, `W`, `H` (вьюпорт),
`D` (расстояние камеры по умолчанию), `seed`, `pi`, `tau`, `e`. Деление на 0 и не-числа → 0;
длина ≤ 600 символов. Ни строк, ни объектов, ни вызовов чужого — выражение может только посчитать
число.

### Почему нет скрипт-функций `(t, api) => scene`

Сознательно не сделано: в Node `vm` — не граница безопасности (выход к `process` через
конструкторы, бомбы памяти на машине с 31 ГБ), в браузере `Function` с «замороженным API» исполняет
чужой код в сессии владельца (XSS: API сервиса с его куками). Выражения + `repeat` + `stagger` +
`letters` + пружины покрывают то же, оставаясь данными.

## Порядок рисования и пределы

Z-буфера нет: элементы (грани, буквы, картинки, линии) сортируются **художником** — по `order`,
потом по глубине центра, дальние первыми. Отсюда:

- **большой пол/плита, на которой стоят объекты, — `order: -1`**: иначе центр огромной грани
  ближе к камере, чем дальние объекты на ней, и пол ляжет поверх (шаблоны «остров» и
  «изометрический титр» так и сделаны);
- пересекающиеся тела не режутся друг другом — разводи их или задай `sort: "object"`/`order`;
- текст и картинка — один элемент со своей глубиной (центр), а не по граням.

Отсечение: тыльные грани (кроме `doubleSided`/плоскостей), ближняя плоскость камеры
(многоугольник режется Сазерлендом — Ходжменом, пол сквозь камеру рисуется), грани вне вьюпорта.

| предел | значение |
|---|---|
| граней в кадре | спокойно до ~4000 (проверка предупреждает), жёстко 20 000 — хвост не рисуется |
| узлов | 5000; копий одного repeat — 500; частиц одного узла — 600 |
| сегменты | sphere ≤ 96×64, cylinder ≤ 128, torus ≤ 128×48, icosphere detail ≤ 4 |
| текст | ≤ 200 символов на узел |
| JSON сцены | ≤ 200 000 символов, вложенность ≤ 40 (сервис) / 24 уровня узлов (движок) |

## Производительность

Замер (Node 24, @napi-rs/canvas 1.0.10, этот ПК; тест «~2000 граней… (замер)» печатает число):

| сцена | кадр 1080×1920 |
|---|---|
| 25 гладких toon-шаров с обводкой + пол, 2136 граней (1053 после отсечения) | **≈ 10–15 мс** |
| шаблоны галереи (кадр в середине) | 1–16 мс |
| mp4 через компоновщик целиком (кадр + x264): остров с облётом / концовка / кинетический текст | 98 / 103 / 48 кадр/с |

Советы: segments поменьше у мелких/далёких объектов (шар 12×7 на заднем плане неотличим от
32×21); россыпь — один `repeat`/`particles`, не сотни узлов; `seams: false` у мелких граней
экономит штрих; обводка (`outline`) на тысячах граней — заметная часть времени; halftone/hatch —
вторая заливка узором на каждую тёмную грань; `text3d` рисует буквы срезами (`slices` ≤ 14) —
у split по буквам их число умножается на буквы.

## Проверка и инструменты агента

- **`get_scene_reference`** — шпаргалка (эта схема коротко) + примеры (`toon_logo`,
  `ortho_2d_motion`, `lowpoly_orbit`, `kinetic_letters`) + список шаблонов галереи.
- **`preview_scene_frame`** — `scene` (без клипа) или `layer_id`; `t` — число или до 4 моментов
  (лист кадров); `w`/`h`, `background`, `width` (540). Тот же компоновщик, что рендер. В ответе —
  ошибки/предупреждения с путём поля, граней в кадре и мс.
- `add_layers` / `update_layer` проверяют слой `scene` движком: ошибки (неизвестный тип, плохое
  выражение, неизвестная кривая, цвет не цвет) — слой не принят с причиной; предупреждения
  (неизвестное поле с подсказкой «может быть, color?», бюджет граней) — в `warnings`.
- Компоновщик: `node node/motion-render.mjs --validate-scene in.json [--fonts-dir …]`, где
  `in.json` — `{scene, w?, h?, t?, dur?}` → JSON `{ok, errors, warnings, stats}` в stdout.
- Редактор: инспектор слоя «3D-сцена» — вьюпорт, камера ручками (тип, облёт, наклон, поле
  зрения/zoom; анимированные поля — только в JSON) и JSON сцены с проверкой на лету.

## Шаблоны галереи (категория «3D»)

`scene-iso-title` (изометрический титр на плите, ортокамера), `scene-logo-spin` (выдавленный
значок с toon-обводкой, пауза — оборот), `scene-parallax-2d` (2D-иллюстрация слоями, пролёт с
параллаксом и туманом), `scene-lowpoly-orbit` (гранёный остров, облёт), `scene-kinetic-text`
(буквы переворотом + волна), `scene-confetti-3d` (3D-конфетти, разлёт, титр на пружине),
`scene-card-flip` (карточка «до/после» с переворотом), `scene-subscribe` (кнопка, колокольчик,
нажатие → «Вы подписаны»). Каждый — один слой `scene`: правь JSON как угодно.

## Пример целиком

```json
{
  "type": "scene", "start": 0, "end": 4, "y": 0.4, "props": { "h": 1200, "scene": {
    "camera": { "orbit": { "elevation": 5 } },
    "style": { "shading": "toon", "bands": 3, "outline": { "color": "#140c2a", "width": 6 } },
    "nodes": [
      { "type": "extrude", "shape": "star", "radius": 260, "spikes": 5, "depth": 90, "color": "#FFD400",
        "position": [0, 150, 0], "rotation": [0, { "rate": 90 }, 0],
        "material": { "rim": { "color": "#ffffff", "strength": 0.7 } },
        "enter": { "from": { "scale": 0 }, "spring": { "stiffness": 170, "damping": 12 } } },
      { "type": "text3d", "text": "НОВИНКА", "size": 110, "depth": 26, "position": [0, -330, 0],
        "color": "#ffffff", "sideColor": "#FFD400", "material": { "outline": { "width": 4 } },
```
