# База знаний: разборы YouTube

Приёмы из роликов, которые мы можем проверить и запустить сами, без человека. Каждый пункт — приём из видео и «у нас»: что сделать и чем мерить.

- [studioigor.md](studioigor.md) — «Студия Игор»: проверка рывков и сгибов в анимации, проверка костей до анимации, «готово, когда», рендер рядом с референсом, гейт по памяти, сверка озвучки распознаванием.
- [anime-in-3d.md](anime-in-3d.md) — аниме в 3D (видео 21–33): карта порога для тени лица, перенос нормалей, свет на персонажа, корпусный контур, шаг по группам костей, смазы и копии.
- [stream-clips.md](stream-clips.md) — нарезки стримов (видео 43–56): «немая реакция» в отборе моментов, внешние сигналы (клипы Twitch, тепловая карта YouTube), схема стрим-шортса, split, подписи, звуки, формулы названий.
- [camera-and-ai-3d.md](camera-and-ai-3d.md) — съёмка 3D-сцен и ИИ в 3D (видео 15–20, 34–42): правила кадра (ось 180°, взгляд, глаза, контраст), 2D-свет, композ, таймшит, новые проверки анимации, правила для агентов.
- [modelling-texturing.md](modelling-texturing.md) — моделирование и текстурирование (видео 1–14): здоровье меша пропсов, «шумная тень», маски источников в 4.5 и light-ноды 5.3, фоны проекцией, швы VRoid, запекание и роспись.
