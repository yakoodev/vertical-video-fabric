# Установка на Windows — простой путь (без командной строки)

Ставится мышкой: установить Docker Desktop, скачать проект, дважды кликнуть установщик.
Время — ~30–40 минут, почти всё это ожидание сборки.

> Всё хранится внутри Docker. GPU не нужен. Команды в этом гайде спрятаны в блоки
> «для продвинутых» — обычному пользователю они не нужны.

---

## Шаг 1. Проверить виртуализацию

Docker на Windows работает поверх виртуализации — обычно она уже включена.

- Нажмите `Ctrl+Shift+Esc` → **Диспетчер задач** → вкладка **Производительность** → **ЦП**.
- Справа внизу строка **«Виртуализация»** должна быть **«Включено»**.
- Если «Отключено» — её включают в BIOS/UEFI (пункт *Intel VT-x* / *AMD-V* / *SVM*). Если не уверены — попросите того, кто настраивал ПК, или загляните в инструкцию к материнской плате.

---

## Шаг 2. Установить Docker Desktop

1. Откройте **https://www.docker.com/products/docker-desktop/** и нажмите **Download for Windows**.
2. Запустите скачанный `Docker Desktop Installer.exe`, жмите **Next/OK**, оставляя галки по умолчанию
   (в т.ч. «Use WSL 2»). В конце — **перезагрузите ПК**, если попросит.
3. Запустите **Docker Desktop** (Пуск → Docker Desktop). Первый старт 1–2 минуты.
   - Если он попросит **установить компонент WSL** — согласитесь и следуйте его подсказке
     (одна кнопка / короткое окно), затем перезапустите Docker Desktop.
4. Дождитесь, пока значок 🐳 (кит) внизу справа в трее станет ровным, а в окне Docker Desktop
   слева внизу будет зелёный статус **Engine running**.

> Docker Desktop должен быть **запущен**, когда вы пользуетесь сервисом. Чтобы он стартовал сам:
> в Docker Desktop → ⚙️ Settings → General → включите «Start Docker Desktop when you sign in».

<details>
<summary>Для продвинутых: поставить через командную строку</summary>

```powershell
winget install -e --id Docker.DockerDesktop
wsl --install   # если WSL ещё не стоит; затем перезагрузка
```
</details>

---

## Шаг 3. Скачать проект

1. Откройте страницу проекта: **https://github.com/yakoodev/vertical-video-fabric**
2. Нажмите зелёную кнопку **`Code`** → **Download ZIP**.
3. Распакуйте архив (правый клик по zip → **Извлечь всё…**) в удобную папку, например в `Документы`.
   Получится папка `vertical-video-fabric-main`.

<details>
<summary>Для продвинутых: через Git (удобно для обновлений)</summary>

```powershell
winget install -e --id Git.Git
git clone https://github.com/yakoodev/vertical-video-fabric.git
```
</details>

---

## Шаг 4. Запустить установщик (один двойной клик)

Убедитесь, что **Docker Desktop запущен** (Шаг 2), затем:

1. Откройте распакованную папку проекта.
2. Дважды кликните по файлу **`setup.cmd`** в корне папки.
   - Если Windows покажет синее окно «Защита Windows» → **Подробнее** → **Выполнить в любом случае**.
3. Установщик задаст пару вопросов прямо в окне:
   - **Gemini API ключ** — вставьте ключ из Google AI Studio (или нажмите Enter, добавите позже).
   - **Токен для входа** — нажмите **Enter**, он сгенерируется автоматически (установщик покажет
     его — **запишите**, он нужен для входа).
   - **Режим** — нажмите Enter (real = публикует; `m` = тест без отправки).
4. На вопрос «Собрать и запустить сейчас?» нажмите **Enter**. Пойдёт сборка (**10–20 минут**, разово).
   Если выскочит запрос брандмауэра Windows — нажмите **«Разрешить доступ»**.
5. По готовности установщик **сам откроет** `http://localhost:8088` в браузере.

## Повседневное управление — через Docker Desktop (мышкой)

Откройте **Docker Desktop** → слева **Containers** → строка проекта `vertical-video-fabric`:

- **▶ / ⏹** — запустить / остановить сервис.
- **⋮ → View details → Logs** — посмотреть, что происходит (логи).
- Сервис открывается на **http://localhost:8088** (когда контейнер запущен).

**Обновить до новой версии:** скачайте свежий ZIP (Шаг 3) в ту же/новую папку и снова дважды
кликните `setup.cmd` — он пересоберёт. Ваши данные (проекты, аккаунты, клипы) сохранятся.

<details>
<summary>Для продвинутых: команды управления и бэкап</summary>

```powershell
docker compose stop          # остановить
docker compose start         # запустить
docker compose logs -f app   # логи
docker compose up -d --build # обновить после git pull

# бэкап всех данных (том vv-fabric-data) в файл vvf-data.tar.gz:
docker run --rm -v vv-fabric-data:/data -v ${PWD}:/backup alpine tar czf /backup/vvf-data.tar.gz -C /data .
```
⚠️ `docker compose down -v` удаляет данные. Обычный `docker compose down` — безопасно.
</details>

## Если что-то пошло не так

| Что видите | Что делать |
|---|---|
| Установщик пишет «Docker не запущен» | Откройте **Docker Desktop** и дождитесь зелёного **Engine running**, затем снова запустите `setup.cmd`. |
| «Защита Windows» при запуске `setup.cmd` | **Подробнее → Выполнить в любом случае** (файл из проекта, безопасен). |
| Docker Desktop не стартует | Не включена виртуализация (Шаг 1) или не сделана перезагрузка после установки. |
| Сборка прервалась | Нет интернета во время сборки — подключитесь и снова запустите `setup.cmd`. |
| `localhost:8088` не открывается | В Docker Desktop → Containers контейнер должен быть запущен (зелёный). Посмотрите Logs. |
| «Invalid token» при входе | Введите тот токен, что показал установщик. Не записали — перенастройте: запустите `setup.cmd` ещё раз и ответьте «y» на вопрос про .env. |
