# Установка на macOS — простой путь (почти без терминала)

Работает на Mac с процессором Intel и Apple Silicon (M1/M2/M3/M4). Ставится мышкой:
установить Docker Desktop, скачать проект, дважды кликнуть установщик.

> Всё хранится внутри Docker. GPU не нужен.

---

## Шаг 1. Установить Docker Desktop

1. Откройте **https://www.docker.com/products/docker-desktop/** → **Download for Mac**.
   Выберите свой чип: **Apple Silicon** (M1–M4) или **Intel**.
2. Откройте скачанный `Docker.dmg` и перетащите **Docker** в **Applications**.
3. Запустите **Docker** (Launchpad → Docker), примите условия, дождитесь в меню-баре (вверху справа)
   ровного значка 🐳 и статуса **Engine running** в окне Docker Desktop.

> Docker Desktop должен быть **запущен**, когда пользуетесь сервисом.

---

## Шаг 2. Скачать проект

1. Откройте **https://github.com/yakoodev/vertical-video-fabric**
2. Зелёная кнопка **`Code`** → **Download ZIP**.
3. Дважды кликните скачанный архив — распакуется папка `vertical-video-fabric-main`
   (перетащите её, например, в `Документы`).

---

## Шаг 3. Запустить установщик (двойной клик)

Убедитесь, что **Docker Desktop запущен**, затем:

1. Откройте папку проекта, найдите файл **`setup.command`**.
2. **Первый запуск macOS может заблокировать файл** («не удаётся проверить разработчика»).
   Тогда: **правый клик по `setup.command` → «Открыть» → в диалоге снова «Открыть»**.
   (Или: Системные настройки → Конфиденциальность и безопасность → внизу «Всё равно открыть».)
3. Откроется окно Терминала и задаст пару вопросов:
   - **Gemini API ключ** — вставьте ключ из Google AI Studio (или Enter — добавите позже).
   - **Токен для входа** — нажмите **Enter**, он сгенерируется (установщик покажет — **запишите**).
   - **Режим** — Enter (real = публикует; `m` = тест без отправки).
4. На «Собрать и запустить сейчас?» — **Enter**. Пойдёт сборка (**10–20 минут**, разово).
5. По готовности установщик **сам откроет** `http://localhost:8088`.

---

## Шаг 4. Войти

Введите **токен**, который показал установщик. Готово 🎉

Дальше — **[Руководство пользователя](user-guide.md)**, подключение аккаунтов — **[Импорт cookies](cookie-import.md)**.

## Управление — через Docker Desktop (мышкой)

Docker Desktop → **Containers** → строка `vertical-video-fabric`:
- **▶ / ⏹** — запустить / остановить.
- **⋮ → View details → Logs** — логи.
- Сервис на **http://localhost:8088** (когда контейнер запущен).

**Обновить:** скачайте свежий ZIP (Шаг 2) и снова дважды кликните `setup.command`. Данные сохранятся.

<details>
<summary>Для продвинутых: через Терминал</summary>

```bash
cp .env.example .env      # заполнить ключи + токен
docker compose up -d --build
docker compose logs -f app
# бэкап тома данных:
docker run --rm -v vv-fabric-data:/data -v "$PWD":/backup alpine tar czf /backup/vvf-data.tar.gz -C /data .
```
</details>

## Если что-то не так

| Симптом | Решение |
|---|---|
| «setup.command не удаётся открыть» | Правый клик → «Открыть» → «Открыть»; либо разрешить в Настройки → Конфиденциальность и безопасность. |
| Установщик пишет «Docker не запущен» | Запустите Docker Desktop, дождитесь **Engine running**, повторите. |
| Сборка прервалась | Нет интернета во время сборки — подключитесь и снова запустите `setup.command`. |
| `localhost:8088` не открывается | В Docker Desktop → Containers контейнер должен быть запущен; посмотрите Logs. |
