# Музыкальный клип одной командой (`tools/music_video`)

Пресет, утверждённый на song15 («темп хороший, оставляем как пресет»), обобщённый для любой песни.
Это CLI-инструмент вне сервиса: Blender остаётся внешней зависимостью, сервис не трогается
(из него берётся только ключ Polza — картинки генерируются `docker exec` в контейнере приложения).

Стили:
- `paper` — песня song15: буквы-вырезки на рваной бумаге, полоски «печатной машинки», рваные листы-переходы, зерно и виньетка;
- `comic` — песня song2: плоский комикс (эталон `refs/ae_showcase/comic_monster_show.mp4`), буквы комикс-леттеринга с контуром и тенью,
  вспышки-звукоподражания, лучи скорости, панели-переходы, волнистая полоса земли.

## Команда

```
python tools/music_video/make.py --song SONG.mp3 --full --style comic --out D:/vvf-offload/songX --stage analyze,plan
# правим OUT/plan.json: картинки, персонажи, сцены, большие слова, шутки
python tools/music_video/make.py --out D:/vvf-offload/songX --stage images --max-rub 60
python tools/music_video/make.py --out D:/vvf-offload/songX --stage prep,stills --stills 30,300,900,1500 --draft
python tools/music_video/make.py --out D:/vvf-offload/songX --stage prep,build,encode,check
```

`--start 15 --end 36` вместо `--full` — участок песни. Шаги можно звать по одному (`--stage`), `all` — все, кроме платного
`images` без `--max-rub`. Blender: `--blender ПУТЬ` или `MV_BLENDER` (по умолчанию ищется `D:/vvf-offload/tools/blender/blender-*/`).
demucs: `--demucs` или `MV_DEMUCS` (аргументы через `|`, например `D:/…/demucs_venv/Scripts/python.exe|-m|demucs`).
Перед рендером шаг ждёт ≥ 6 ГБ свободной памяти (`--min-ram`).

Результат в OUT: `<имя>.mp4` (H.264 + AAC, faststart; при > 48 МБ ещё `_tg.mp4` двухпроходным x264), `sheet.jpg` (24 кадра),
`sync_check.mp4` (клип + бегущая спектрограмма вокала с метками), `analysis.json`, `plan.json`; рабочее — в `OUT/work`.

## Тайминг — главное правило

- Время слова = **атака слога на вокальном стеме** (demucs htdemucs → спектральный поток 120–6000 Гц, шаг 5 мс).
  Whisper только говорит, *какое* это слово: на пении его время уезжает на 0.2–1 с.
- Большая буква становится видна за 1–2 кадра до атаки и «бьёт» на +1 кадр; многосложное слово собирается по слогам
  (каждая группа букв — на атаку своего слога).
- Склейки — на долях сетки (темп автокорреляцией + подбор фазы), встряска камеры — на сильных долях, «наезд-удар» — на большом слове.
- Проверка: `work/spec_NN.png` (спектрограммы по 24 с: жёлтые — атаки, красные — слова с номерами) и `sync_check.mp4`.
- Если длинный прогон Whisper «залип» (повторы на припевах), `--rewhisper 12-16,16-20.5` перераспознаёт окна,
  `tools/music_video/probe.py OUT 12-16 …` — просто послушать окна. Опечатки и сдвиги — в `lyrics_fix` плана.

## plan.json

```jsonc
{
 "style": "comic", "fps": 30, "size": [1080, 1920],
 "censor": [],                                  // префиксы слов, которые в подписях заменяются плашкой «БИП» (пусто — как спето)
 "lyrics_fix": {"79": {"text": "пузатый"}, "191": {"at": 80.19}},
 "characters": {"bear": "big chubby brown cartoon bear, tan-cream belly …"},   // «паспорт» персонажа, вклеивается в промпт
 "image_style": {"common": "…", "plate": "…", "cutout": "…"},
 "images": {
   "forest": {"kind": "plate", "prompt": "…"},                                    // фон 9:16
   "bear":   {"kind": "cutout", "key": "green", "chars": ["bear"], "prompt": "…"},   // персонаж на хромакее
   "bear_run": {"kind": "cutout", "refs": ["bear"], "chars": ["bear"], "prompt": "…"},  // новая поза — с референсом
   "hunter": {"kind": "cutout", "split": "area", "prompt": "…"}                  // несколько объектов → hunter#0, hunter#1
 },
 "scenes": [{
   "id": "chorus", "from": "w:150-0.1",           // начало сцены (прилипает к доле); конец — начало следующей
   "bg": "glade" | {"burst": true, "bg": "cream", "line": "purple"},
   "camera": {"move": "push|pull|orbit|truck_l|truck_r|crane_up|crane_down|zoom|drift", "amount": 1.0, "roll": -2},
   "ground": {"body": "purple", "stripe": "lime", "y": 0.94},   "bushes": [{"x": 0.1, "w": 0.55}],
   "props": [{"img": "bear", "x": 0.7, "y": 0.87, "h": 0.6, "in": "w:155", "out": null,
              "anim": "pop|still|peek|slide|run|fly|shake", "flip": false, "args": {"from_x": -0.4, "end_at": "w:166"}}],
   "words": [{"text": "ПОЖМЁТ\nЛАПУ!", "at": ["w:157", "w:159"], "y": 0.22, "w": 0.82, "fill": "lime", "fill2": "yellow",
              "out": "w:160"}],
   "captions": {"from": "w:150", "to": "w:159", "y": 0.075, "skip": []},
   "sfx": [{"text": "ХРЯСЬ!", "at": "w:166", "x": 0.5, "y": 0.47, "h": 0.2, "dur": 0.9, "kind": "sfx|cool|censor"}],
   "panels": [{"img": "handshake", "at": "w:157", "dur": 0.85, "w": 0.78}],
   "transition": "cut|panel|burst"
 }]
}
```

Время в плане: число — секунда песни; `"w:155"` — атака слова №155 (номера в выводе `analyze` и на `spec_NN.png`);
`"w:155.1"` — второй слог; `"b:24"` — доля №24; к любому можно приписать сдвиг `"w:57-0.1"`.
Координаты — доли кадра (x слева, y сверху); у персонажа `y` — линия ног, `h` — высота.

## Картинки (nano-banana)

- ~3 ₽ за картинку 1K; потолок — `--max-rub`; реальный расход по балансу Polza до/после пишется в `work/spend.log`.
- Персонажи — на ровном хромакее (`key: green`; если на персонаже есть зелень — `magenta`), фон отделяется только связной
  с краем областью, поэтому зелёное внутри силуэта не выгрызается.
- Одинаковые персонажи: новая поза = `refs` на исходную картинку + «паспорт» из `characters` (цвета, одежда, приметы).
- Перед сборкой смотреть каждую картинку крупно: число рук/ног/пальцев/глаз, слипшиеся предметы, кривой текст.
  Брак — `--stage images --max-rub N --force id,id` (перегенерирует только эти).

## Проверка перед отправкой

- `--stage prep,stills --stills … --draft` — быстрые кадры (секунды), лист `work/stills_sheet.jpg`.
- После рендера `check`: застывшие отрезки > 1 с выводятся списком; `sheet.jpg` — смотреть глазами
  (буквы не режутся краем кадра, персонажи стоят на земле с тенью, фон не открывает чёрный край при движении камеры).
- `sync_check.mp4` — красные метки ударов букв должны стоять на жёлтых атаках.

## Устройство

| файл | что делает |
|---|---|
| `make.py` | вход, шаги |
| `audio.py`, `analyze.py`, `probe.py` | стем, атаки, сетка, слова |
| `plan.py` | черновик плана |
| `images.py`, `polza_gen.py` | картинки через контейнер (`polza_gen.py` выполняется внутри) |
| `styles.py`, `kit_comic.py`, `kit_paper.py` | как выглядят буквы/плашки/вспышки/фоны в каждом стиле |
| `resolve.py` | план → `work/scene.json` (кадры, доли экрана) + текстуры |
| `blender_build.py` | сцена Blender по `scene.json`: павильон на сцену, своя камера, всё ключуется покадрово |
| `encode.py`, `check.py`, `sync_check.py` | mp4, лист кадров, сверка синхрона |

Чего нет из ручной версии song15: симуляции ткани, проекции дороги, дыма и пыли — это были разовые находки под тот клип;
общий движок даёт фон-лист, полосу земли, кусты, персонажей, слова, подписи, вспышки, вставки и переходы.
Пример полного плана — `tools/music_video/examples/song2_comic.json`.
